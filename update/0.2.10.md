# Dokumentasi Rilis Update v0.2.10

Penyesuaian posisi dan tampilan ikon show/hide passcode.

**Tanggal Release**: 18 Agustus 2026  
**Jenis Update**: Patch UI

## Whats New

1. Ikon show/hide diposisikan di dalam sisi kanan input passcode.
2. Input passcode kembali menggunakan lebar penuh.
3. Background dan border tombol ikon dihapus agar tampil menyatu dengan input.
4. Area klik ikon tetap berukuran 34px di dalam input.

## Spesifikasi

| Komponen | File | Perubahan |
|---|---|---|
| Input passcode | `src/backend/static/css/styles.css` | Padding kanan untuk ruang ikon |
| Toggle icon | `src/backend/static/css/styles.css` | Absolute positioning, transparent background |

## Handling

1. Ikon tetap memiliki focus-visible state.
2. Toggle tetap mengubah tipe input antara password dan text.
3. Tidak memengaruhi payload atau validasi passcode.
4. Deploy perubahan frontend/backend menggunakan:
   ```bash
   docker compose build web
   docker compose up -d --no-deps web
   ```
