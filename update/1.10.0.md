# v1.10.0

## Whats New

- Menetapkan decision runtime Virtual Brand sebagai pure toggle.

## Spesifikasi

- `penangguhan` tidak dipakai untuk menentukan action VB.
- Masa aktif atau kedaluwarsa layanan tidak dipakai untuk menentukan action VB.
- Setelah jadwal reguler tersedia dan waktu berada dalam jam operasional,
  `vb_brands.applied_status` menjadi sumber target `ON/OFF`.
- Status Shopee `CLOSED` di dalam jam reguler tetap dianggap jadwal khusus dan
  tidak dipaksa menjadi `OPEN`.

## Handling

- Worker VB tetap identik dengan worker bot-OC.
- Override decision hanya berada pada entry point `main-vb/src/decision.py`.
- Bot-OC tetap menggunakan decision engine dan gate administrasinya sendiri.
- Perubahan tidak menjalankan daemon atau action Shopee.
