# Release Note 1.13.9

## Whats New
- Standarisasi UX writing untuk status outlet pada tabel Virtual Brand (VB) di Admin Dashboard:
  - Fase pembukaan outlet (`PENDING_OPEN`): `"Bot sedang dalam proses pembukaan outlet"`.
  - Fase penutupan outlet (`PENDING_PAUSE`): `"Bot sedang dalam proses penutupan outlet"`.
  - Fase pengambilan data/jadwal outlet (`NOT_FETCHED_YET`, `FETCH_RETRYING`, `STATUS_UNKNOWN`): `"Bot sedang dalam proses pengambilan data outlet"`.
- Perataan proporsi dan pembersihan jarak kolom (gap) pada layout 5-kolom tabel Virtual Brand.
- Memperbaiki parsing Google Sheet CSV pada endpoint sinkronisasi Agency (`/api/v1/admin/sync-source`) dengan pencocokan nama header secara dinamis (*dynamic header pattern matching*):
  - Menggantikan pembacaan indeks kolom statis dengan deteksi nama header adaptif pada `fetch_merchant_outlets()` di `src/core/sheets.py` dan `main-vb/src/core/sheets.py`.
  - Mencegah error duplikasi Store ID (*502 Bad Gateway*) ketika ada penambahan kolom baru pada spreadsheet kontrol (seperti penambahan kolom `WA Pemilik` di Kolom B).

## Spesifikasi
- **Target Files**:
  - `src/backend/templates/admin_dashboard.html`: Implementasi fungsi `getVbStatusSubtext` dan `getVbStatusPresentation` khusus untuk scope Virtual Brand.
  - `src/backend/static/css/styles.css`: Proporsi grid layout 5 kolom `.vb-store-table-head` dan `.vb-store-row` yang seimbang dan rapat.
  - `src/core/sheets.py` & `main-vb/src/core/sheets.py`: Helper `find_col` untuk memetakan kolom spreadsheet secara dinamis berdasarkan nama header.
  - `tests/test_dashboard_label_contract.py`: Penambahan unit test kontrak label UX writing `test_vb_status_ux_writing_contract`.

## Handling
- Penyesuaian UX writing diisolasi khusus pada handler Virtual Brand melalui `getVbStatusSubtext` dan `getVbStatusPresentation` agar status deskriptif tampil seragam dan tidak mengganggu kontrak tab Agency.
- Penyesuaian parser Google Sheet menjamin tombol Fetch Data pada halaman Agency selalu sukses mengimpor data ke PostgreSQL.
