# Release Note 1.13.9

## Whats New
- Memperbaiki parsing Google Sheet CSV pada endpoint sinkronisasi Agency (`/api/v1/admin/sync-source`) dengan pencocokan nama header secara dinamis (*dynamic header pattern matching*):
  - Menggantikan pembacaan indeks kolom statis (0 s/d 10) dengan deteksi nama header adaptif pada `fetch_merchant_outlets()` di `src/core/sheets.py` dan `main-vb/src/core/sheets.py`.
  - Mencegah error duplikasi Store ID (*502 Bad Gateway*) ketika ada penambahan kolom baru pada Google Sheet (seperti penambahan kolom `WA Pemilik` di Kolom B).
  - Menjaga kompatibilitas mundur (*backward compatibility*) dengan susunan kolom lama jika nama header tidak dikenali.

## Spesifikasi
- **Target Files**:
  - `src/core/sheets.py` & `main-vb/src/core/sheets.py`:
    - Menambahkan helper `find_col(patterns, exclude, default)` untuk mencocokkan nama header secara case-insensitive.
    - Memetakan field `nama_pemilik`, `hp`, `import_status`, `paket`, `tanggal_mulai_layanan`, `tanggal_berakhir_layanan`, `username`, `password`, `nama_portal`, `store_id`, `nama_panjang_outlet`, dan `vercel_password` secara dinamis.
    - Menjaga paritas *byte-for-byte identical* antara `src/core/sheets.py` dan `main-vb/src/core/sheets.py`.

## Handling
- Menjamin fitur **Fetch Data** pada halaman Agency di Dashboard Admin selalu berhasil mengimpor data spreadsheet ke PostgreSQL tanpa terpengaruh perubahan atau penambahan kolom baru di Google Sheet.
