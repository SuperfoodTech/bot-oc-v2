# Dokumentasi Rilis Update v0.1.0

Dokumentasi rilis untuk penambahan fitur **Agency Force Close Panel & Worker Service** pada sistem FoodMaster Bot-OC.

---

## Whats New

1. **Modul Terpisah Agency (`src/agency/`)**:
   - Menambahkan modul `src/agency/` untuk mengisolasi logika eksekusi *Force Close* outlet `churn` dari patroli SaaS reguler.
   - Integrasi parser Google Sheet CSV publik sebagai *source of truth* data outlet agency.
   - *Decision Engine* khusus yang **hanya mengeksekusi `CLOSE` atau `STOP`** (tanpa ada logika `OPEN`).

2. **Tab GUI Baru Dashboard Admin (`Agency / Churn`)**:
   - Menambahkan tab navigasi baru `Agency / Churn` pada `admin_dashboard.html` (`admin_tab_agency.html`).
   - Menyediakan sakelar **Toggle `Auto Force Close` [ ON / OFF ]**.
   - Menyediakan tabel visual 16 outlet target berstatus `Churn` beserta tombol aksi per-baris **"Close"**.

3. **Interaksi Keamanan Toggle & Tombol Action**:
   - Ketika **Auto Force Close = ON**: Tombol eksekusi manual "Close" pada setiap baris outlet di tabel otomatis **ter-disable (`disabled`)**.
   - Ketika **Auto Force Close = OFF**: Tombol eksekusi manual "Close" pada setiap baris outlet di tabel **aktif (`enabled`)**.

4. **Persistensi State System Settings**:
   - Menambahkan tabel database PostgreSQL `system_settings` untuk menyimpan status toggle `auto_force_close_enabled` agar tidak ter-reset saat server di-restart.

---

## Spesifikasi

- **Target Platform**: ShopeeFood (Filtered dari CSV Google Sheet).
- **Format Target Status**: Status `Churn` (Target penutupan paksa).
- **Rule Evaluasi Keputusan**:
  - Jika status toko Shopee = `OPEN` / `BUKA` $\rightarrow$ Action: `ACTION_CLOSE`, Target: `CLOSE`.
  - Jika status toko Shopee = `PAUSE` / `OFF` / `CLOSED` $\rightarrow$ Action: `ACTION_STOP`, Target: `CLOSE` (No Change).
- **API Endpoints Baru**:
  - `GET /api/v1/agency/outlets`: Membaca data outlet churn dan status toggle.
  - `POST /api/v1/agency/toggle-auto`: Mengubah status toggle Auto Force Close.
  - `POST /api/v1/agency/force-close-single`: Menjalankan force close single outlet (hanya aktif jika Auto Force Close = OFF).

## Handling

1. **Zero-Downtime Web Deployment**:
   - Update backend/frontend web di-deploy tanpa menginterupsi bot patroli SaaS yang sedang berjalan:
     ```bash
     docker compose build web
     docker compose up -d --no-deps web
     ```
2. **Penanganan Chrome Profile Missing**:
   - Bot runner Agency (`src/agency/runner.py`) secara otomatis melakukan penanganan pengecekan profil browser.
   - Jika `profiles/agency_profile` belum disiapkan, runner akan mencatat log peringatan secara aman dan membatalkan eksekusi Selenium tanpa menyebabkan crash pada aplikasi web.
