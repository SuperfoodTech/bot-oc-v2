# Dokumentasi Rilis Update v0.2.3

Penyesuaian desain tabel Churn Bot agar lebih konsisten dengan tabel Operasional Outlet dan Logs.

**Tanggal Release**: 18 Agustus 2026  
**Jenis Update**: Patch UI

## Whats New

1. **Penyeragaman Lebar Kolom Tabel Churn Bot**:
   - Kolom nomor, outlet, merchant, Store ID, status, waktu pengecekan, dan aksi diberi proporsi lebar yang konsisten.
   - Tabel desktop menggunakan layout kolom tetap agar isi tidak mengubah lebar kolom secara tidak terduga.

2. **Penyeragaman Alignment**:
   - Header dan isi tabel Churn Bot diratakan ke tengah.
   - Tombol `Close` diposisikan konsisten di tengah kolom aksi.

3. **Penyesuaian Tombol `Close`**:
   - Tombol diubah menjadi gaya outline dengan teks dan border merah.
   - State hover menggunakan latar merah muda agar selaras dengan tombol kontrol lain pada dashboard.

## Spesifikasi

| Komponen | File | Perubahan |
|---|---|---|
| Tabel Churn Bot | `src/backend/templates/admin_tab_agency.html` | Tetap menggunakan struktur `data-table` dan layout responsif |
| Kolom Desktop | `src/backend/static/css/styles.css` | `table-layout: fixed` dengan proporsi kolom total 100% |
| Alignment | `src/backend/static/css/styles.css` | Header, cell, dan tombol aksi rata tengah |
| Tombol Close | `src/backend/static/css/styles.css` | Outline merah dengan hover merah muda |

## Handling

1. Pada layar mobile, tabel tetap menggunakan format kartu per baris agar seluruh informasi outlet tetap terbaca.
2. Tombol `Close` tetap disabled ketika `Auto Force Close` aktif.
3. Perubahan hanya berada pada frontend dan tidak mengubah endpoint, data, atau logika force close.
4. Deployment perubahan frontend/backend menggunakan:
   ```bash
   docker compose build web
   docker compose up -d --no-deps web
   ```
