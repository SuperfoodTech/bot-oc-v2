# Dokumentasi Rilis Update v0.2.3

Penyesuaian desain tabel Churn Bot, penanganan pencocokan nama merchant dengan karakter khusus/underscore, serta perbaikan konsistensi penentuan status `NOT_FOUND`.

**Tanggal Release**: 18 Agustus 2026  
**Jenis Update**: Patch UI & Agency Browser Fix

## Whats New

1. **Penyeragaman Lebar Kolom Tabel Churn Bot**:
   - Kolom nomor, outlet, merchant, Store ID, status, waktu pengecekan, dan aksi diberi proporsi lebar yang konsisten.
   - Tabel desktop menggunakan layout kolom tetap agar isi tidak mengubah lebar kolom secara tidak terduga.

2. **Penyeragaman Alignment & Styling Tombol**:
   - Header dan isi tabel Churn Bot diratakan ke tengah.
   - Tombol `Close` diposisikan konsisten di tengah kolom aksi dengan gaya outline border merah.

3. **Normalisasi Nama Merchant & Konsistensi Status `NOT_FOUND`**:
   - Skrip JS dan penguji header UI Shopee (`.merchantName`) pada `src/agency/browser.py` kini otomatis membersihkan akhiran underscore (`_`) dan spasi berlebih.
   - Jika setelah 3x percobaan klik bot tetap gagal memverifikasi perpindahan merchant, bot melempar `MerchantNotFoundError` secara eksplisit sehingga runner memperbarui status outlet di database menjadi **`NOT_FOUND`** (bukan tertahan sebagai `UNKNOWN`).

## Spesifikasi

| Komponen | File | Perubahan |
|---|---|---|
| Browser Agency | `src/agency/browser.py` | Normalisasi pencocokan merchant (`rstrip('_')`) & eksplisit `MerchantNotFoundError` |
| Tabel Churn Bot | `src/backend/templates/admin_tab_agency.html` | Struktur `data-table` dan layout responsif |
| Kolom Desktop | `src/backend/static/css/styles.css` | `table-layout: fixed` dengan proporsi kolom total 100% |
| Alignment & Tombol | `src/backend/static/css/styles.css` | Header, cell, dan tombol `Close` outline rata tengah |

## Handling

1. Pada layar mobile, tabel tetap menggunakan format kartu per baris agar seluruh informasi outlet tetap terbaca.
2. Tombol `Close` tetap disabled ketika `Auto Force Close` aktif.
3. Perubahan backend agency secara otomatis memperbarui status outlet yang gagal di-switch menjadi `NOT_FOUND`.
4. Deployment perubahan backend web menggunakan:
   ```bash
   docker compose build web
   docker compose up -d --no-deps web
   ```
