# Dokumentasi Rilis Update v0.2.21

Memperbaiki navigasi kembali setelah mitra berhasil dibuat.

**Tanggal Release**: 18 Agustus 2026  
**Jenis Update**: Patch UX

## Whats New

1. Setelah `Simpan & generate link` berhasil, tombol kembali langsung menuju operasional outlet.
2. Modal konfirmasi data terhapus tidak lagi muncul pada flow yang sudah selesai.

## Spesifikasi

| Komponen | File | Perubahan |
|---|---|---|
| Leave guard | `src/backend/templates/admin_add_merchant.html` | Tombol kembali menghormati status submit sukses melalui `isLeaving` |

## Handling

1. Modal konfirmasi tetap muncul jika user meninggalkan form yang belum disimpan.
2. Submit gagal tetap dianggap sebagai form aktif dan tetap memakai konfirmasi.
3. Deploy perubahan menggunakan:
   ```bash
   docker compose build web
   docker compose up -d --no-deps web
   ```
