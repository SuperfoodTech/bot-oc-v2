# Update v1.3.0

## Whats New

- Dashboard admin desktop sekarang memiliki tombol `Lihat jadwal` pada detail outlet.
- Panel jadwal dapat dibuka dan disembunyikan tanpa mengubah data.

## Spesifikasi

- Jadwal dibaca dari `shopee_regular_hours` berdasarkan `store_id` outlet.
- Panel menampilkan jadwal Senin sampai Minggu dan beberapa interval waktu jika tersedia.
- Local owner `Yolo` menggunakan data dummy jadwal untuk pengujian tampilan ketika data XHR belum tersedia.

## Handling

- Tombol ditempatkan berdampingan dengan `Hapus akun` pada layout desktop.
- Tampilan bersifat informasi saja; tidak ada kontrol edit jadwal.
- Jadwal kosong ditampilkan sebagai `Tutup`.
