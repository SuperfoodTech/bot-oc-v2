# Release 1.34.0

### Whats New
- **Shopee In-Browser Virtual Switch Engine & Zero-DOM Probing Architecture**:
  - Mengintegrasikan mekanisme In-Browser Instant Virtual Switch pada `src/shopee/store_status.py` dan `main-vb/src/shopee/store_status.py` yang mengeliminasi kebutuhan navigasi DOM halaman penuh (`driver.get()`) dan jeda hidrasi React SPA (2-4 detik per toko).
  - Menyuntikkan cookie context `shopee_foody_mid = target_merchant_id` dan menetralisir `shopee_tob_entity_id = ""` secara atomik (<1ms) pada browser session aktif sebelum mengeksekusi request `fetch()` API Shopee (`/api/seller/store`, `/regular-hours`, `/special-hours`, `/action/open`, `/action/pause`).
  - Memangkas latensi pemeriksaan status toko (probing) dari 3-5 detik menjadi <150ms per outlet, dan mempercepat siklus patroli portal 30-50 toko dari 2-4 menit menjadi hanya 4-8 detik.
  - Mengakselerasi eksekusi aksi on-demand (Express Lane) dari dashboard mitra/admin menjadi instan (<500ms).
- **Production-Hardened Multi-Merchant & Multi-Domain Resilience**:
  - **Entity Neutralizer Contract**: Memastikan `shopee_tob_entity_id` selalu disetel ke string kosong `""` pada domain `.shopee.co.id` (mengeliminasi error `1130001: token invalid`).
  - **Single-Domain Cookie Scoping**: Menghapus duplikasi cookie lintas domain (`window.location.hostname` dan host-only) dengan pembersihan `max-age=0` dan penulisan tunggal ke `.shopee.co.id; path=/` untuk mencegah tabrakan header HTTP Cookie.
  - **Dynamic MID Resolution**: Mengeliminasi hardcode fallback `"14367488"` pada `worker.py` dan default argumen `store_status.py`, menggantikannya dengan fallback dinamis `(targetMid || existingMid || targetSid)` sesuai kontrak `/trx` (mengeliminasi error `1130014: merchant authority invalid`).
  - **Non-Destructive Session Recovery**: Menghapus pemanggilan `_deliberate_logout_and_relogin` saat dropdown merchant gagal mencocokkan nama portal, menandai grup outlet dilewati (*skip with warning*), dan menjaga sesi browser 24/7 tetap aktif tanpa gangguan.
  - **Robust Case & Whitespace Dropdown Matching**: Menstandarkan pencocokan portal Shopee secara case-insensitive dan whitespace-normalized, serta mendukung virtual scroll `rc-virtual-list-holder`.
- **Worker Patrol Loop Optimization**:
  - Mengoptimalkan patrol loop pada `main-bot/src/worker.py` dan `main-vb/src/worker.py` (tetap dijaga 100% byte-for-byte identical) dengan `switch_store_context`.
- **Comprehensive Contract Testing**:
  - Menambahkan test suite `tests/test_virtual_switch_contract.py` (11 test case) untuk memvalidasi injeksi cookie, netralisasi entity ID, dynamic MID, pencegahan context bleeding, dan mekanisme fallback.

### Spesifikasi
- Modul Terdampak:
  - `src/shopee/store_status.py`: Penambahan `is_on_shopee_partner()`, `switch_store_context()`, netralisasi `shopee_tob_entity_id`, eliminasi cookie collision, dan default `merchant_id: Optional[str] = None`.
  - `main-vb/src/shopee/store_status.py`: Sinkronisasi 100% byte-for-byte dengan `src/shopee/store_status.py`.
  - `main-bot/src/worker.py`: Penggantian `ensure_business_hours_page` dengan `switch_store_context` pada patrol loop, dynamic MID resolution, dan non-destructive merchant switch recovery.
  - `main-vb/src/worker.py`: Sinkronisasi 100% byte-for-byte dengan `main-bot/src/worker.py`.
  - `src/core/browser.py` & `main-vb/src/core/browser.py`: Normalisasi dropdown matching dan eliminasi destructive logout recovery pada target_name mismatch.
  - `tests/test_virtual_switch_contract.py`: 11 test case untuk validasi arsitektur virtual switch dan production resilience.
  - `.agents/AGENTS.md`: Update dokumentasi rilis 1.34.0.

### Handling
- Semua aksi on-demand (Buka/Tutup/Pause) dieksekusi secara instan (<500ms) tanpa jeda reload halaman.
- Semua pemeriksaan status operasional dan jadwal toko tetap diproteksi dengan guard ketat `StoreIdentityMismatch`.
- Sesi login browser aman dari loop relogin/logout destruktif saat terjadi anomali nama portal di DB.
