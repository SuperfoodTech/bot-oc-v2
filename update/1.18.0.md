# Release Update 1.18.0 - WhatsApp Gateway Microservice (`bot-wa`)

## Whats New

Penambahan struktur direktori dan MVP microservice `bot-wa/` (Node.js + Baileys + Express) yang didesain secara modular untuk dijalankan di server terpisah. Service ini bertindak sebagai WhatsApp Gateway untuk menerima notifikasi aksi bot patroli (`bot-oc` dan `bot-vb`) melalui HTTP Webhook REST API.

---

## Spesifikasi

1. **Service Gateway (`bot-wa`)**:
   - Dibuat menggunakan Node.js dengan framework Express.js dan `@whiskeysockets/baileys`.
   - Menggunakan mekanisme `useMultiFileAuthState` untuk menyimpan sesi login WhatsApp secara persisten pada direktori `./auth_info_baileys` / Docker Volume (`wa_session_data`).
   - Menyediakan endpoint REST API:
     - `GET /health`: Cek kesehatan service.
     - `GET /api/v1/status`: Cek status koneksi WhatsApp dan QR raw.
     - `POST /api/v1/webhook/bot-action`: Menerima notifikasi event aksi (`ACTION_OPEN`, `ACTION_CLOSE`, `ACTION_SKIPPED`, `BOT_ERROR`).
     - `POST /api/v1/send-message`: API pengiriman pesan langsung.
   - Proteksi API Key menggunakan header `X-API-Key`.
   - Penanganan antrean pesan internal (*Message Queue*) dengan throttling delay **1.5 detik** untuk mencegah pemblokiran nomor (*Anti-Ban Rate Limiting*).

2. **Dokumentasi Terstruktur**:
   - `ARCHITECTURE.md`: Penjelasan topologi jaringan terpisah, sequence diagram, reconnection policy, dan strategi fault tolerance.
   - `CONTRACT.md`: Spesifikasi lengkap kontrak API Webhook, HTTP headers, JSON Schema per event, response status code, dan snippet client Python.
   - `README.md`: Panduan pemindahan folder ke server lain, konfigurasi environment `.env`, scan QR code, dan perintah pengujian `curl`.

3. **Core Notifier & Virtual Brand Discord Integration (`bot-oc` & `bot-vb`)**:
   - Penambahan fungsi `send_wa_webhook_async` pada `src/core/notifier.py` dan `main-vb/src/core/notifier.py` khusus untuk `bot-oc` (Virtual Brand di-bypass dari WA).
   - Penambahan pendukung environment `DISCORD_WEBHOOK_VB_URL` untuk mengisolasi saluran notifikasi Discord khusus Virtual Brand (`bot-vb`).
   - Penambahan fungsi `send_discord_vb_group_summary` dengan format rekap per-VB Group:
     - `🟢 VB GROUP BERHASIL DIBUKA BOT` (Full Success Open)
     - `🟠 VB GROUP SEBAGIAN BERHASIL DIBUKA BOT` (Partial Open)
     - `🔴 VB GROUP BERHASIL DITUTUP BOT` (Full Success Close)
     - `🟠 VB GROUP SEBAGIAN BERHASIL DITUTUP BOT` (Partial Close)
   - Penyesuaian footer embed menjadi `"FoodMaster Virtual Brand Engine"` saat beroperasi di konteks VB.

---

## Handling

- **Deployment Terpisah**:
  - Folder `bot-wa` dapat dipindahkan ke server lain kapan saja tanpa mengubah codebase `bot-oc` / `bot-vb`.
  - Di server WhatsApp target, jalankan `docker compose up -d --build` dan lakukan scan QR code via konsol log container.
- **Konfigurasi Webhook Environment**:
  - `WA_GATEWAY_URL` & `WA_GATEWAY_KEY`: Digunakan oleh `bot-oc` untuk mengirim notifikasi ke merchant via WhatsApp.
  - `DISCORD_WEBHOOK_VB_URL`: Digunakan oleh `bot-vb` untuk mengirim notifikasi rekap VB Group ke channel Discord khusus Virtual Brand.
