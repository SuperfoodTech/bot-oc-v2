# Dokumentasi Rilis Update v0.2.17

Pengikatan akses dashboard mitra berdasarkan link slug.

**Tanggal Release**: 18 Agustus 2026  
**Jenis Update**: Security dan access-flow patch

## Whats New

1. Login pada `/mitra/{slug}` sekarang memvalidasi passcode terhadap akun yang memiliki slug tersebut.
2. Passcode yang sama antar-owner tidak lagi salah masuk ke owner pertama yang ditemukan.
3. Session passcode browser dibuat scoped per slug sehingga membuka link mitra lain tidak membawa sesi owner sebelumnya.
4. Slug baru menggunakan token acak yang lebih panjang dan sulit ditebak.
5. Satu akun owner tetap dapat memiliki banyak outlet dengan satu link dan satu passcode.

## Spesifikasi

| Komponen | File | Perubahan |
|---|---|---|
| Login scope | `src/backend/main.py`, `src/backend/models.py`, `src/backend/db.py` | Request login menerima slug dan query akun dibatasi oleh slug |
| Browser session | `src/backend/templates/user_dashboard.html` | Penyimpanan passcode dipisahkan berdasarkan slug |
| Link generation | `src/backend/db.py` | Token slug baru memakai random URL-safe token |

## Handling

1. Link lama tetap berfungsi selama slug dan akun masih tersedia.
2. Route `/app` tetap memakai fallback login legacy tanpa slug.
3. Satu owner dengan beberapa outlet tetap memakai akun merchant yang sama.
4. Deploy perubahan menggunakan:
   ```bash
   docker compose build web
   docker compose up -d --no-deps web
   ```
