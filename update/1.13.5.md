# Release Note 1.13.5

## Whats New
- Mengatasi kendala login dan timeout pada bot Virtual Brand (VB):
  - Memperbaiki tombol konfirmasi "Lanjutkan" pada flow autentikasi Shopee agar diklik via JavaScript DOM execution secara instan, mencegah timeout 60 detik renderer Selenium.
  - Memperbaiki deteksi `active_name` pada browser session dengan fallback nama merchant UI jika nama belum terdeteksi dari API `GetUserInfo`, serta mencegah deliberate logout recovery saat `active_id` telah valid pada mode warmup.
  - Menambahkan dukungan override file konfigurasi `.env.vb` pada template service systemd `bot-vb.service` agar whitelist `ALLOWED_USERNAMES=allvbadmin` tidak tertimpa oleh file `.env` pusat.
  - Menambahkan stub `db.init_state()` pada modul adapter database VB (`main-vb/src/db.py`) untuk menjaga kompatibilitas pemanggilan inisialisasi daemon.
  - Menjaga paritas identik *byte-for-byte* antara `src/core/browser.py` dan `main-vb/src/core/browser.py`.

## Spesifikasi
- **Target Files**:
  - `src/core/browser.py` & `main-vb/src/core/browser.py`:
    - Mengganti klik tombol `Lanjutkan` / `Continue` dengan JavaScript DOM click.
    - Menambahkan pengecekan UI name fallback jika `active_name` bernilai `"Unknown Merchant"`.
    - Menjaga sesi tetap valid saat `active_id` terdeteksi tanpa memicu logout paksa pada mode warmup (`target_name is None`).
  - `systemd/bot-vb.service`:
    - Menambahkan direktif `EnvironmentFile=-%PROJECT_DIR%/.env.vb` di bawah `.env` untuk mendukung override environment khusus VB.
  - `main-vb/src/db.py`:
    - Menambahkan fungsi `init_state()` sebagai no-op kompatibilitas daemon engine.
  - `.gitignore`:
    - Menambahkan pola `.env.*` untuk mengabaikan file override environment lokal.

## Handling
- Mencegah proses login bot VB hang selama 60 detik pada dialog "Lanjutkan" Shopee Partner.
- Memastikan scheduler bot VB dapat men-dispatch seluruh portal merchant secara stabil tanpa terblokir whitelist akun atau logout rekursif.
