# Dokumentasi Rilis Update v0.2.23

Penyederhanaan modal hapus data.

**Tanggal Release**: 18 Agustus 2026  
**Jenis Update**: Patch visual

## Whats New

1. Emoji peringatan di modal hapus data dihapus.
2. Label `Peringatan` tetap dipertahankan agar konteks risiko tetap jelas.

## Spesifikasi

| Komponen | File | Perubahan |
|---|---|---|
| Delete modal | `src/backend/templates/admin_dashboard.html` | Menghapus emoji dari panel peringatan |

## Handling

1. Modal tetap menampilkan informasi bahwa data yang dihapus tidak dapat dikembalikan.
2. Tidak ada perubahan pada proses delete.
3. Deploy perubahan menggunakan:
   ```bash
   docker compose build web
   docker compose up -d --no-deps web
   ```
