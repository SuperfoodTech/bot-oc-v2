# Dokumentasi Rilis Update v0.2.24

Penyederhanaan visual dashboard mitra berdasarkan hasil review UI.

**Tanggal Release**: 19 Agustus 2026  
**Jenis Update**: Minor UX/UI improvement

## Whats New

1. Badge status Shopee di setiap card outlet dihapus.
2. Card outlet, card akun, dan aktivitas dikembalikan ke surface putih netral.
3. Rotasi warna pastel per outlet tidak lagi terlihat pada dashboard mitra.
4. Kontrol otomatisasi menggunakan surface abu-abu netral.
5. Tombol `Tutup sementara` dibuat netral agar tidak semua action terlihat destructive.
6. Error aksi outlet menggunakan toast hitam-putih tanpa native alert.
7. Emoji pada pesan outlet ditangguhkan admin dihapus.

## Spesifikasi

| Komponen | File | Perubahan |
|---|---|---|
| Outlet status | `src/backend/templates/user_dashboard.html` | Menghapus badge status Shopee |
| Card styling | `src/backend/static/css/styles.css` | Surface dashboard mitra dinetralkan |
| Action feedback | `src/backend/templates/user_dashboard.html`, `src/backend/static/css/styles.css` | Menambahkan toast untuk error aksi outlet |

## Handling

1. Warna merah tetap digunakan untuk action `Buka sekarang` dan status penting.
2. Fitur ganti akun/logout belum diubah sesuai arahan.
3. Deploy perubahan menggunakan:
   ```bash
   docker compose build web
   docker compose up -d --no-deps web
   ```
