# Dokumentasi Rilis Update v0.2.27

Penanganan error keunikan email Google saat penambahan atau pengubahan data mitra.

**Tanggal Release**: 19 Agustus 2026  
**Jenis Update**: Patch & Fix Stabilitas API

## Whats New

1. Penanganan error duplikasi email Google pada saat admin menambahkan atau mengedit outlet mitra.
2. Mengganti kegagalan aplikasi internal (HTTP 500 / Exception ASGI) menjadi respon HTTP 400 (Bad Request) dengan pesan kesalahan yang jelas ketika email Google yang dimasukkan sudah digunakan oleh akun lain.

## Spesifikasi

| Komponen | File | Perubahan |
|---|---|---|
| Validasi Database | `src/backend/db.py` | Validasi keunikan email Google secara case-insensitive (`LOWER(google_email)`) di fungsi `_context` dan `admin_edit_outlet` |
| REST API Endpoints | `src/backend/main.py` | Penangkapan `ValueError` di endpoint `admin_create_outlet` (`POST /api/v1/admin/outlets`) dan `admin_edit_outlet` (`POST /api/v1/admin/outlets/edit`) untuk mengembalikan `HTTPException` dengan status 400 |

## Handling

1. Jika email Google sudah digunakan oleh akun admin atau merchant lain, sistem akan memblokir penyimpanan dan mengembalikan respon error "Email Google sudah terdaftar." tanpa menyebutkan username akun yang menggunakannya demi alasan keamanan dan privasi.
2. Deploy perubahan menggunakan:
   ```bash
   docker compose build web
   docker compose up -d --no-deps web
   ```
