# Dokumentasi Rilis Update v0.3.2

Penyempurnaan kontrol pause mitra, custom date-time picker, dan konsistensi data Sheet.

**Tanggal Release**: 20 Agustus 2026
**Jenis Update**: Feature, UX & Data Fix

## Perubahan

1. Password dashboard mitra dari kolom `Vercel Kata Sandi` tidak lagi di-reset ke `Master@00@` saat startup atau Fetch.
2. Opsi `Waktu Lain` pada pause menggunakan target tanggal dan waktu akhir, bukan hanya jumlah menit.
3. Ditambahkan custom date-time picker dengan:
   - Kalender berbahasa Indonesia.
   - Selector jam `00–23`.
   - Selector menit `00–59`.
   - Format 24-jam tanpa AM/PM.
   - Label dan preview waktu WIB.
4. Popover picker tidak lagi terpotong pada desktop maupun mobile.
5. Modal pause diposisikan lebih center pada mode mobile.
6. Tombol `Buka sekarang` dan `Tutup sementara` yang duplikatif dihapus; toggle menjadi kontrol utama outlet.
7. Kolom `Dashboard Mitra` menggunakan tombol buka dan icon copy, tanpa menampilkan URL panjang.
8. Header tabel daftar outlet mengikuti nama kolom utama Google Sheet.
