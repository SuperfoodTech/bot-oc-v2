# Dokumentasi Rilis Update v0.2.18

Konfirmasi visual saat link dashboard berhasil disalin.

**Tanggal Release**: 18 Agustus 2026  
**Jenis Update**: Patch UX

## Whats New

1. Toast `Link dashboard berhasil disalin` muncul setelah aksi salin berhasil.
2. Toast menghilang otomatis setelah sekitar 1,8 detik.
3. Toast bersifat fixed sehingga tidak menggeser layout card review.

## Spesifikasi

| Komponen | File | Perubahan |
|---|---|---|
| Copy feedback | `src/backend/templates/admin_add_merchant.html` | Menambahkan status toast dan timer otomatis |
| Copy feedback style | `src/backend/static/css/styles.css` | Toast responsif untuk desktop dan mobile |

## Handling

1. Toast hanya ditampilkan setelah clipboard berhasil menerima link.
2. State ikon copy tetap berubah sementara sebagai feedback tambahan.
3. Deploy perubahan menggunakan:
   ```bash
   docker compose build web
   docker compose up -d --no-deps web
   ```
