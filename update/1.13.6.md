# Release Note 1.13.6

## Whats New
- Mengubah nama kolom jam operasional pada tabel Agency (`admin_tab_operasional.html`) dan tabel Virtual Brand (`admin_dashboard.html`) menjadi `Jam Hari Ini`.
- Mengubah penamaan dan urutan kolom pada tabel Agency (`#adminTable`):
  - `Owner` diubah menjadi `Nama Pemilik`.
  - `Merchant` diubah menjadi `Nama Portal`.
  - Urutan kolom `Outlet` dan `Store ID` ditukar, dengan `Outlet` diubah namanya menjadi `Nama Listing` (urutan kolom: `Nama Pemilik`, `Nama Portal`, `Nama Listing`, `Store ID`, `Jam Hari Ini`, `Link`, `Link Mitra`, `Toggle`).
- Menghapus kartu ringkasan metric `Subscription Aktif` pada baris atas statistik Agency (`.stats-grid`), menyisakan 3 kartu ringkas (`Total Outlet`, `Sedang Buka`, `Sedang Tutup`).
- Menghapus field filter `Subscription` dan `Paket` pada bilah filter desktop (`.outlet-filter-toolbar`) dan sheet filter mobile, serta menyesuaikan grid filter menjadi 4 kolom filter + tombol reset.
- Memperbarui rendering baris sel tabel dan pembagian lebar kolom CSS pada `styles.css` agar proporsi lebar sel konsisten (`Nama Listing` di kolom 3 selebar 18%, `Store ID` di kolom 4 selebar 9%).
- Memperbarui label kartu mobile outlet Agency (`<dt>Jam Hari Ini</dt>`) dan label sel responsif Virtual Brand (`.vb-store-field-label`) agar selaras dengan header tabel desktop.

## Spesifikasi
- **Target File**:
  - `src/backend/templates/admin_tab_operasional.html`:
    - Menghapus kartu `metric-card-subscription` dan tombol segmen mobile `subscription`.

    - Mengubah urutan cell `<td>` pada fungsi `renderAdminTable`: meletakkan cell `${s.store_name}` pada kolom 3 dan `.store-id-cell` pada kolom 4.
    - Mengubah header kolom tabel Virtual Brand `<span>Jam Operasional</span>` pada `.vb-store-table-head` menjadi `<span>Jam Hari Ini</span>`.
    - Mengubah label baris sel Virtual Brand `<span class="vb-store-field-label">Jam Operasional</span>` pada `.vb-store-hours` menjadi `<span class="vb-store-field-label">Jam Hari Ini</span>`.
