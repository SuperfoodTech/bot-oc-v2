# Dokumentasi Rilis Update v0.2.0

Penambahan **Agency Churn Bot Patrol Engine** — browser terisolasi dengan patrol loop aktif, status inspection real-time, dan trigger force close berbasis tombol.

---

## Whats New

1. **`src/agency/browser.py` (Modul Baru)**:
   - Browser module eksklusif untuk Agency Churn Bot, terpisah sepenuhnya dari `core/browser.py`.
   - Menggunakan Chrome Profile: `src/data/chrome_profile` (profile `Default`).
   - Menggunakan session: `src/data/session.json`.
   - Menggunakan credentials: `src/data/credentials allvbadmin.json`.
   - Fungsi utama: `init_agency_driver()`, `get_agency_session()`, `switch_to_merchant()`, `get_outlet_shopee_status()`, `execute_force_close()`.
   - **Isolation guarantee**: window Chrome ini tidak pernah berbagi state, driver, atau session dengan `fm-bot` (SaaS patrol). Zero race condition.

2. **Patrol Loop (`src/agency/runner.py`)**:
   - Background thread daemon `agency-patrol` yang berjalan terus-menerus.
   - Grouping outlet per `merchant_name`, diurutkan: merchant dengan outlet **terbanyak** → **terkecil**.
   - Default: **inspect-only** (read status, tidak ada action).
   - Force Close hanya dieksekusi ketika:
     - Auto Force Close toggle = `ON`, atau
     - Tombol manual "Close" per baris diklik oleh admin.
   - Status hasil inspeksi disimpan ke tabel PostgreSQL `agency_outlet_status` setiap cycle.
   - Interval patroli: 5 menit per cycle penuh.

3. **Status Real-Time di Dashboard**:
   - Kolom baru `Status` di tabel Churn Bot: badge `OPEN` (merah), `CLOSED` (hijau), `UNKNOWN` (abu-abu).
   - Data status diambil dari DB, bukan dari Google Sheet.
   - Auto-refresh setiap 30 detik saat tab Agency aktif.

4. **Tombol Kontrol Patroli**:
   - Tombol **"Mulai Patroli"** / **"Hentikan Patroli"** di control bar atas.
   - Status patroli (`Patroli Aktif` / `Patroli Berhenti`) ditampilkan di sebelah tombol.

5. **Database Migration**:
   - Tabel baru `agency_outlet_status` (migration `004_add_agency_outlet_status.sql`).
   - Field: `store_id`, `merchant_name`, `brand`, `shopee_status`, `last_checked`, `last_action`.

6. **API Endpoint Baru**:
   - `POST /api/v1/agency/patrol/start`: Memulai patrol loop.
   - `POST /api/v1/agency/patrol/stop`: Menghentikan patrol loop.
   - `GET /api/v1/agency/patrol/status`: Status patrol saat ini.
   - `GET /api/v1/agency/outlets` diperbarui: status real-time di-merge dari DB.

## Spesifikasi

- **Chrome Profile**: `src/data/chrome_profile` — terisolasi dari `chrome_profile_auto7313` milik bot SaaS.
- **Session File**: `src/data/session.json` — dioverwrite setiap kali session baru berhasil dibuat.
- **Credentials**: `src/data/credentials allvbadmin.json` — format `{ "key": { "username": ..., "password": ... } }`.
- **Grouping Cycle**: `merchant_name` yang punya outlet terbanyak diproses pertama, paling sedikit terakhir.
- **Trigger Action**:
  - Auto Force Close `ON` → bot otomatis close semua outlet `OPEN` saat patroli.
  - Auto Force Close `OFF` → hanya inspect, tidak ada action. Tombol manual per baris aktif.

## Handling

1. **Zero-Downtime Deployment** (perubahan backend/frontend):
   ```bash
   docker compose build web
   docker compose up -d --no-deps web
   ```

2. **Race Condition Prevention**:
   - Patrol agency menggunakan `chrome_profile` berbeda (`src/data/chrome_profile` vs `src/data/chrome_profile_auto7313`).
   - Driver agency tidak pernah diakses oleh thread SaaS bot, dan sebaliknya.
   - `_patrol_lock` (threading.Lock) memastikan akses driver aman saat manual trigger bersamaan dengan loop.

3. **OTP Safety**:
   - Login menggunakan Chrome Profile trusted device — OTP tidak akan dipicu jika profile masih valid.
   - Jika OTP terdeteksi, bot abort login dan log error tanpa hanging.
