# v1.10.8

## Whats New

- Menambahkan layer verifikasi Vibium ke eksperimen `test_switch_xhr.py` untuk cross-check state UI dashboard dan struktur request partner setelah reach dashboard via `src/core/browser.py`.
- Menyambungkan helper UI `browser.return_to_selector()` ke `test_switch_xhr.py` agar flow test lebih dekat dengan perilaku dashboard nyata: buka profile, klik `Pilih Merchant Lain`, lalu observasi trigger `MerchantDetect` sebelum XHR manual.
- Menambahkan artefak read-only Vibium berupa screenshot desktop/mobile, accessibility tree, interactive map, ringkasan state UI, teks halaman, HTML snapshot, dan struktur network verifikasi.
- Memperjelas hasil uji live bahwa XHR `SwitchMerchant` belum memindahkan merchant aktif dashboard meskipun endpoint dapat merespons `200`, dan pada percobaan terbaru gateway mengembalikan `errorCode=90004`.

## Spesifikasi

- `test_switch_xhr.py` sekarang:
  - reach dashboard lebih dulu memakai `browser.get_session(..., close_browser=False)`,
  - memanggil helper `browser.return_to_selector(driver)` untuk meniru klik profile lalu `Pilih Merchant Lain`,
  - memeriksa apakah resource `PartnerMerchantDetectServer/MerchantDetect` muncul atau daftar merchant terlihat di overlay,
  - mengambil merchant list via XHR `PartnerMerchantDetectServer/MerchantDetect`,
  - mengeksekusi switch via XHR `PartnerMerchantDetectServer/SwitchMerchant`,
  - menjalankan dua stage verifikasi Vibium (`before-switch` dan `after-switch`) secara headless dan read-only.
- Layer Vibium mengekspor state Selenium aktif ke storage state temporary, lalu membuka dashboard di browser Vibium untuk mengambil:
  - `ui_state.json`,
  - `network_structure.json`,
  - `map.txt`,
  - `a11y_tree.txt`,
  - `page_text.txt`,
  - `page_html.html`,
  - screenshot desktop dan mobile.
- Output ringkasan CLI sekarang menampilkan merchant UI aktif, body excerpt singkat, resource Shopee yang terlihat, serta hasil verifikasi read-only ke endpoint `GetUserInfo` dan `MerchantDetect`.

## Handling

- Artefak Vibium disimpan di direktori temporary `/tmp/vibium-switch-xhr-*` dan state file sensitif untuk restore Vibium dihapus kembali setelah dipakai.
- Token mentah tidak ditampilkan di ringkasan teks; output hanya menampilkan token yang sudah dimasking.
- Exit code `2` tetap dipakai bila merchant aktif dashboard tidak benar-benar berubah setelah percobaan XHR switch.
