# Dokumentasi Rilis Update v0.2.6

Penyederhanaan tampilan halaman khusus Tambah Mitra.

**Tanggal Release**: 18 Agustus 2026  
**Jenis Update**: Patch UX

## Whats New

1. Header brand dihapus dari halaman `/admin/mitra/tambah` agar fokus pengguna langsung ke workflow form.
2. Tombol kembali diperbesar menjadi kontrol dengan area klik minimum 44px, border, dan background yang jelas.
3. State hover tombol kembali menggunakan warna aksen lembut agar affordance tetap terlihat.

## Spesifikasi

| Komponen | File | Perubahan |
|---|---|---|
| Halaman Tambah Mitra | `src/backend/templates/admin_add_merchant.html` | Header brand tidak lagi dirender |
| Tombol Back | `src/backend/static/css/styles.css` | Ukuran, padding, border, dan hover diperjelas |

## Handling

1. Header brand pada dashboard utama tidak berubah.
2. Tombol kembali tetap mengarah ke `/admin/dashboard?tab=outlets`.
3. Perubahan hanya memengaruhi layout dan navigasi visual halaman Tambah Mitra.
4. Deploy perubahan frontend/backend menggunakan:
   ```bash
   docker compose build web
   docker compose up -d --no-deps web
   ```
