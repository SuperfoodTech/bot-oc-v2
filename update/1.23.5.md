# Release 1.23.5 - ShopeeFood Hyperlink in Virtual Brand Discord Notifications

Integrasi hyperlink ShopeeFood `[Link]` di sebelah kanan Store ID pada seluruh tipe pesan notifikasi Discord bot Virtual Brand (`bot-vb`).

---

## Whats New

1. **ShopeeFood Hyperlink Integration**:
   - Seluruh pesan notifikasi Discord bot Virtual Brand (`send_discord_vb_group_summary`) kini menyertakan hyperlink `[Link]` langsung ke halaman toko ShopeeFood di sebelah kanan Store ID (`✅ Nama Outlet — <store_id> • [Link](url)`).
   - Format URL yang digunakan sama persis dengan tabel web dashboard: `https://shopee.co.id/universal-link/now-food/shop/<store_id>`.

2. **Universal Notification Type Coverage**:
   - Hyperlink ShopeeFood aktif pada seluruh variasi skenario notifikasi:
     - **Mode Brand Toggle (Kolektif)**: Full Open (🟢), Full Close (🔴), Partial Open/Close (🟠), Full Fail Open/Close (🔴).
     - **Mode Auto-Guarding (Targeted Outlet)**: Full Open (🟢), Full Close (🔴), Partial Open/Close (🟠), Full Fail Open/Close (🔴).
   - Hyperlink terpasang baik pada daftar outlet berhasil (`✅`) maupun daftar outlet gagal (`❌`).

3. **Graceful Edge-Case Handling**:
   - Jika suatu item tidak memiliki `store_id` (misalnya input teks sederhana tanpa ID), bot secara otomatis mempertahankan format teks bersih tanpa menghasilkan tautan kosong (`[Link]()`).

---

## Spesifikasi

1. **Format Markdown Discord**:
   - URL: `https://shopee.co.id/universal-link/now-food/shop/{safe_store_id}`
   - Baris item: `{name} — {store_id} • [Link]({url})`
2. **Modul yang Diperbarui**:
   - `main-vb/src/core/notifier.py`: Pembaruan helper `_format_item(item)` dan penambahan impor `urllib.parse`.
   - `src/core/notifier.py`: Penyelarasan format helper `_format_item(item)` dan impor `urllib.parse`.
   - `tests/test_vb_notifier_links.py`: Unit test komprehensif untuk validasi hyperlink item notifikasi Discord.

---

## Handling

1. **Integritas Worker**:
   - File `main-vb/src/worker.py` tetap 100% identik *byte-for-byte* dengan `main-bot/src/worker.py`. Perubahan format notifikasi terkonsentrasi murni pada layer `notifier.py`.
2. **Keamanan Panjang Pesan**:
   - Batas maksimal panjang teks embed description (3900 karakter) tetap terjaga untuk mencegah kegagalan pengiriman ke Discord Webhook akibat batas payload Discord.
