# Release Update 1.18.4 - Optimalisasi Memori Lanjutan Tahap 1 (CDP Request Blocking & Renderer Process Limit)

## Whats New

Penerapan optimasi memori lanjutan Tahap 1 untuk instance browser Chromium/Chrome pada `bot-oc` dan `bot-vb`. Pembaruan ini mengimplementasikan pembatasan proses renderer Chrome (`--renderer-process-limit=1` & `--disable-site-isolation-trials`) dan pencegahan pengunduhan aset non-kritis (font web dekoratif serta telemetri/pelacak pihak ketiga) menggunakan Chrome DevTools Protocol (CDP) `Network.setBlockedURLs`.

---

## Spesifikasi

1. **Pembatasan Proses Renderer Chrome (`_init_driver`)**:
   - `--renderer-process-limit=1`: Membatasi Chromium agar hanya mengalokasikan satu proses renderer aktif untuk navigasi, menghemat ~50MB–80MB RAM dari alokasi proses sekunder yang tidak terpakai.
   - `--disable-site-isolation-trials`: Mencegah isolasi proses sub-origin berlebih yang memicu spawning proses worker tambahan.

2. **Network Interception & URL Blacklisting via CDP (`Network.setBlockedURLs`)**:
   - Mengaktifkan `Network.enable` pada CDP saat inisialisasi driver.
   - Memblokir pengunduhan font web dekoratif: `*.woff`, `*.woff2`, `*.ttf`, `*.eot`.
   - Memblokir script pelacak dan telemetri pihak ketiga: `*google-analytics.com*`, `*googletagmanager.com*`, `*facebook.net*`, `*sensorsdata*`, `*doubleclick.net*`.
   - **Boundary Safety**: File script core Shopee (`*.js`), stylesheet (`*.css`), dan seluruh endpoint API (`/api/*`) tetap diizinkan 100% tanpa gangguan.
   - Dilengkapi proteksi `try...except` agar jika inisialisasi CDP mengalami kendala pada versi browser tertentu, proses inisialisasi browser tetap berjalan lancar (*graceful degradation*).

3. **Audit Logika & Kepatuhan Arsitektur**:
   - Tuas rollback `checkpoint-1.18.3-baseline` (commit `20a74a9`) terkunci dan siap digunakan jika diperlukan pemulihan state baseline.
   - Modul worker `main-bot/src/worker.py` dan `main-vb/src/worker.py` tidak diubah dan tetap 100% identik *byte-for-byte*.
