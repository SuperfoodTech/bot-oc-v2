# Release Update 1.18.1 - Virtual Brand Discord Group Summary Hook & Zero-Downtime Reload

## Whats New

Perbaikan integrasi pengiriman notifikasi Discord rekap group Virtual Brand (`send_discord_vb_group_summary`) pada adapter runtime `main-vb/src/db.py` serta pembaruan loader konfigurasi `_get_webhook_url()` di `main-vb/src/core/notifier.py` dan `src/core/notifier.py` agar membaca file `.env` / `.env.vb` secara dinamis tanpa menginterupsi atau me-restart daemon bot patroli Selenium (`bot-vb.service`).

---

## Spesifikasi

1. **Brand Summary Aggregator Hook (`main-vb/src/db.py`)**:
   - Menambahkan tracking aksi `_record_pending_brand_action()` yang mengaitkan setiap aksi outlet (`ACTION_OPEN`, `ACTION_CLOSE`, dsb.) ke entitas `vb_brands.id` dan `vb_brands.name`.
   - Mengimplementasikan `_flush_pending_brand_notifications()` yang dipicu saat siklus batch/sync selesai (`store_id == "SYSTEM"`).
   - Mengambil seluruh outlet aktif di bawah brand terkait untuk menghitung status konsistensi (*All Succeeded*, *Partial*, atau *All Failed*) dan mengirimkan ringkasan 6 skenario embed Discord melalui `send_discord_vb_group_summary()`.
   - Menjaga kepatuhan paritas: `main-vb/src/worker.py` tetap 100% identik (*byte-for-byte*) dengan `main-bot/src/worker.py`.

2. **Dynamic Environment Loader (`notifier.py`)**:
   - Memperbarui helper `_get_webhook_url()` pada `main-vb/src/core/notifier.py` dan `src/core/notifier.py` untuk memuat `DISCORD_WEBHOOK_VB_URL` langsung dari file `.env` / `.env.vb` via `dotenv.dotenv_values()` secara real-time.
   - Perubahan webhook URL dapat langsung terbaca oleh daemon yang sedang aktif tanpa memerlukan restart process atau pemutusan sesi browser Selenium.

3. **Konfigurasi Webhook Discord**:
   - Memasang `DISCORD_WEBHOOK_VB_URL=https://discord.com/api/webhooks/1537384478727606415/N55iktoA7axC-u7ZHt9d6_AzmopoAVkiRgOMtAofXnqLIYyv0rRGoZ_bH6d-4TrJJ7Xr` pada `.env` dan `.env.vb`.

---

## Handling

- **Zero-Downtime Execution**:
  - Seluruh pembaruan langsung aktif pada iterasi patroli berikutnya tanpa me-restart service `bot-vb.service` maupun `bot-oc.service`.
- **Deduplikasi**:
  - Notifikasi ringkasan dilindungi oleh cache hash signature dengan TTL 5 menit untuk mencegah pesan duplikat saat kondisi status tidak berubah.
