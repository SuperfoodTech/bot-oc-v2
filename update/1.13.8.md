# Release Note 1.13.8

## Whats New
- Mengimplementasikan pengambilan dan sinkronisasi nama outlet asli (*Store Name*) dari API Shopee Foody ke database PostgreSQL khusus untuk Virtual Brand (VB):
  - Mengekstrak field `data.store.name` dari respons API Shopee `/api/seller/store` pada fungsi `get_actual_store_status` saat bot mengakses halaman *Business Hours*.
  - Menambahkan fungsi adapter `update_outlet_name(store_id, store_name)` pada `main-vb/src/db.py` untuk memperbarui kolom `outlets.long_name` secara otomatis setiap kali nama outlet terdeteksi pada siklus patroli VB.
  - Menjaga perilaku `main-bot` (Bot O/C reguler) tetap tidak terpengaruh melalui stub *no-op* pada `src/backend/db.py`.
  - Mempertahankan paritas *byte-for-byte identical* antara `main-bot/src/worker.py` dan `main-vb/src/worker.py`.
- Memperbarui presentasi tabel Virtual Brand di Dashboard Admin (`admin_dashboard.html` & `styles.css`):
  - Menambahkan kolom mandiri `Nama Listing` pada tabel Virtual Brand (`.vb-store-table`), sehingga urutan kolom tabel menjadi: `Portal`, `Nama Listing`, `Store ID`, `Status`, `Jam Hari Ini`.
  - Kolom `Nama Listing` menampilkan nama asli outlet (`outlet.storeName`), sedangkan kolom `Portal` fokus menampilkan nama portal/merchant beserta indikator status live.

## Spesifikasi
- **Target Files**:
  - `src/shopee/store_status.py` & `main-vb/src/shopee/store_status.py`:
    - Mengambil nilai `store_data.get("name")` dan mengembalikannya dalam key `"store_name"` pada dictionary return `get_actual_store_status`.
  - `main-vb/src/db.py`:
    - Mengimplementasikan `update_outlet_name(store_id: str, store_name: str)` untuk menjalankan query `UPDATE outlets SET long_name = %s, updated_at = now() WHERE store_id = %s AND (long_name IS NULL OR long_name <> %s)`.
  - `src/backend/db.py`:
    - Menyediakan stub `update_outlet_name(store_id: str, store_name: str)` (no-op) agar pemanggilan worker tidak mengubah data outlet Agency.
  - `main-vb/src/worker.py` & `main-bot/src/worker.py`:
    - Menambahkan pemanggilan `db.update_outlet_name(outlet.store_id, store_name)` dan pembaruan `outlet.nama_panjang_outlet = store_name` saat `live_info.get("store_name")` terdeteksi.
  - `src/backend/templates/admin_dashboard.html`:
    - Menambahkan header `<span>Nama Listing</span>` pada `.vb-store-table-head` dan elemen sel `.vb-store-name` pada `.vb-store-row`.
  - `src/backend/static/css/styles.css`:
    - Mengatur grid `.vb-store-table-head` dan `.vb-store-row` menjadi 5 kolom (`minmax(130px, 1fr) minmax(180px, 1.4fr) minmax(90px, 0.75fr) minmax(140px, 1.15fr) minmax(130px, 1fr)`).
    - Menambahkan styling `.vb-store-name` dan `.vb-store-name-text` (font-size 13px, font-weight 600, color #23272f).

## Handling
- Memastikan nama listing outlet asli yang terdaftar di Shopee otomatis terisi ke database saat bot membuka menu Business Hours, menggantikan nama fallback generik (misal `"Lakubudi - 21897114"` menjadi `"Warung Lontong Sayur, WonderFood"`).
- Memastikan paritas engine worker antara `main-bot` dan `main-vb` tetap 100% konsisten tanpa percabangan logika internal.
