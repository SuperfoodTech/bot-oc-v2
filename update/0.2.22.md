# Dokumentasi Rilis Update v0.2.22

Mencegah request delete terkirim dua kali.

**Tanggal Release**: 18 Agustus 2026  
**Jenis Update**: Patch bug

## Whats New

1. Tombol `Ya, Hapus Data` langsung dinonaktifkan saat proses delete dimulai.
2. Klik berulang tidak lagi mengirim request DELETE kedua untuk Store ID yang sama.
3. Label tombol berubah menjadi `Menghapus...` selama proses berlangsung.

## Spesifikasi

| Komponen | File | Perubahan |
|---|---|---|
| Delete modal | `src/backend/templates/admin_dashboard.html` | Menambahkan lock request dan disabled state pada tombol submit |

## Handling

1. Setelah berhasil, modal ditutup dan data dimuat ulang.
2. Jika gagal, tombol kembali aktif agar admin dapat mencoba lagi.
3. Deploy perubahan menggunakan:
   ```bash
   docker compose build web
   docker compose up -d --no-deps web
   ```
