# Dokumentasi Rilis Update v0.2.11

Penyempurnaan review dan perlindungan data isian pada halaman Tambah Mitra.

**Tanggal Release**: 18 Agustus 2026  
**Jenis Update**: Patch UX

## Whats New

1. Tombol `Batal` di area review dihapus agar hanya ada satu primary action, yaitu `Simpan & generate link`.
2. Ringkasan review ditambahkan field `Merchant`.
3. Navigasi keluar setelah form mulai diisi menampilkan modal konfirmasi.
4. Modal menyediakan pilihan:
   - `Lanjutkan`: meninggalkan halaman dan menghapus data isian.
   - `Batal`: tetap berada di halaman dan mempertahankan data.

## Spesifikasi

| Komponen | File | Perubahan |
|---|---|---|
| Review summary | `src/backend/templates/admin_add_merchant.html` | Field Merchant ditambahkan |
| Review action | `src/backend/templates/admin_add_merchant.html` | Tombol Batal dihapus |
| Leave confirmation | `src/backend/templates/admin_add_merchant.html` | Modal custom dan beforeunload guard |

## Handling

1. Modal hanya muncul jika user sudah mengubah data form.
2. Form kosong dapat ditinggalkan tanpa konfirmasi tambahan.
3. Tombol `Batal` pada modal menutup modal dan mengembalikan fokus ke arrow back.
4. Deploy perubahan frontend/backend menggunakan:
   ```bash
   docker compose build web
   docker compose up -d --no-deps web
   ```
