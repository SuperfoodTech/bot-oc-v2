# Update 1.14.0

## Whats New
- Penarikan (*fetch*) dan penyimpanan data Jadwal Khusus (*Special Hours*) Shopee Foody (`/api/seller/store/special-hours`) pada engine patroli bot saat berada di halaman Business Hours untuk Bot O/C reguler (`main-bot`) dan Virtual Brand (`main-vb`).
- Penyimpanan data terstruktur `shopee_special_hours` (`jsonb`) ke tabel `outlet_states` PostgreSQL.
- Visualisasi Jadwal Khusus pada Admin Dashboard:
  - **Tab Agency**: Ditampilkan di dalam Drawer Detail Outlet (`.outlet-detail-panel`) pada seksi "Jadwal khusus Shopee".
  - **Tab Virtual Brand (VB)**: Ditampilkan sebagai kolom ke-6 "Jadwal Khusus" di sebelah kanan kolom "Jam Hari Ini" pada tabel `.vb-store-table` dan di dalam Drawer Jadwal VB.

## Spesifikasi
- **Database**:
  - `database/migrations/014_shopee_special_hours.sql`: `ALTER TABLE outlet_states ADD COLUMN IF NOT EXISTS shopee_special_hours jsonb;`.
- **Shopee API Client**:
  - `src/shopee/store_status.py` & `main-vb/src/shopee/store_status.py`: Penambahan fungsi `get_special_hours(driver, store_id)` dengan validasi sesi cookie, timeout 5 detik AbortController, dan validasi identitas toko (`StoreIdentityMismatch`).
  - `src/shopee/__init__.py` & `main-vb/src/shopee/__init__.py`: Export `get_special_hours`.
- **Bot Patroli Worker**:
  - `main-bot/src/worker.py` & `main-vb/src/worker.py`: Integrasi sinkronisasi jadwal khusus otomatis dan update DB saat patroli halaman Business Hours. Paritas worker terjaga 100% *byte-for-byte*.
- **Backend & Database Adapter**:
  - `src/backend/db.py` & `main-vb/src/backend/db.py`: Penambahan `update_shopee_special_hours` dan serialisasi `shopee_special_hours` pada query outlet.
  - `main-vb/src/db.py`: Penambahan `update_shopee_special_hours`.
  - `src/backend/vb.py`: Penyertaan field `shopee_special_hours` pada endpoint list & detail brand VB.
- **Frontend & CSS**:
  - `src/backend/templates/admin_dashboard.html`: Helper `formatSpecialHoursDate`, `formatSpecialHoursIntervals`, `getAdminSpecialHoursMarkup`, `getVbSpecialHoursCellMarkup`, penambahan kolom ke-6 header/baris tabel VB, dan integrasi drawer Agency & VB.
  - `src/backend/static/css/styles.css`: Layout grid 6 kolom `.vb-store-table-head` & `.vb-store-row`, styling `.vb-store-special-hours`, `.vb-special-item`, `.admin-special-schedule-row`, dan perbaruan cache-buster query version `styles.css?v=20260915-special-hours-v5`.
- **Tests**:
  - `tests/test_special_hours_store_identity.py`: Unit test verifikasi kontrak endpoint special hours dan proteksi mismatch identitas toko.
  - `tests/test_regular_hours_store_identity.py`: Penyelarasan ekspektasi error `StoreIdentityMismatch`.
  - `tests/test_schedule_ui_layout_contract.py`: Verifikasi kontrak UI layout 6 kolom VB dan keberadaan query special hours.

## Handling
- Validasi identitas toko (`data.store_id == requested_store_id`) diterapkan ketat pada penarikan jadwal khusus sehingga respon dari toko lain langsung ditolak dengan `StoreIdentityMismatch` dan tidak mencemari data outlet.
- Zero-downtime deployment sukses diaplikasikan ke container `web` (`fm-backend`) tanpa menginterupsi service bot dan database.
- Seluruh 75 unit test pada test suite terverifikasi lulus (100% pass).
