# v1.8.0

## Whats New

- Menyatukan source code `browser.py` Bot O/C dan Bot VB.

## Spesifikasi

- `src/core/browser.py` dan `main-vb/src/core/browser.py` identik 100%.
- Path credential, session, dan Chrome profile dipilih melalui environment
  variable, sehingga source code tidak perlu bercabang untuk VB.
- Default Bot O/C tetap dipertahankan.
- Bot VB tetap menggunakan konfigurasi `VB_*` yang sudah tersedia.

## Handling

- Perubahan logic browser cukup dilakukan pada `src/core/browser.py`, lalu
  salinannya harus diperbarui identik pada `main-vb/src/core/browser.py`.
- Verifikasi wajib menggunakan `cmp -s` sebelum commit.
- Tidak ada bot atau request Shopee yang dijalankan dalam perubahan ini.
