# Release Note 1.13.3

## Whats New
- Memperbarui standar UX writing pada riwayat aktivitas log audit di Dashboard Mitra (`user_dashboard.html`) dan drawer detail outlet Dashboard Admin (`admin_dashboard.html`).
- Format teks judul aktivitas diselaraskan secara eksplisit dengan pelaku dan tindakan:
  - Buka oleh Admin: `"Outlet dibuka oleh Admin"`
  - Buka oleh Mitra: `"Outlet dibuka oleh Merchant"`
  - Buka oleh Bot otomatis: `"Bot berhasil membuka outlet"`
  - Tutup oleh Admin: `"Outlet ditutup oleh Admin"`
  - Tutup oleh Mitra: `"Outlet ditutup oleh Merchant"`
  - Tutup oleh Bot otomatis: `"Bot berhasil menutup outlet"`
  - Penangguhan dicabut: `"Penangguhan outlet dicabut oleh Admin"`
  - Penangguhan aktif: `"Outlet ditangguhkan oleh Admin"`
  - Perpanjangan layanan: `"Layanan diperpanjang oleh Admin"`
- Menambahkan informasi baris `Store ID <store_id>` di bawah nama outlet pada kartu log aktivitas, serta menyelaraskan format timestamp waktu menjadi `DD MMM YYYY, HH:mm WIB` (misal: `09 Sep 2026, 10:42 WIB`).

## Spesifikasi
- **Target File**:
  - `src/backend/templates/user_dashboard.html`:
    - Memperbarui `ACTION_LABELS` dan `getHistorySummary(log, actionLabels)`.
    - Memperbarui `formatIndonesianTime(isoStr)` untuk menghasilkan format waktu lengkap `DD MMM YYYY, HH:mm WIB`.
    - Menambahkan rendering elemen `Store ID ${l.store_id}` pada kartu log `fetchHistory()`.
    - Memperbarui mock data demo lokal `createLocalBotDemoLogs()` dengan `store_id`.
  - `src/backend/templates/admin_dashboard.html`:
    - Memperbarui `ACTION_LABELS` dan `getHistorySummary(log, actionLabels)` pada drawer detail outlet.
    - Menambahkan fungsi helper `formatHistoryLogTimestamp(value)` untuk format waktu `DD MMM YYYY, HH:mm WIB`.
    - Menambahkan rendering elemen `Store ID ${l.store_id}` pada daftar log drawer `fetchOutletDetailHistory(storeId)`.
  - `tests/test_dashboard_label_contract.py`:
    - Menambahkan unit test `test_history_logs_ux_writing_contract` untuk memverifikasi konsistensi string label UX writing riwayat aktivitas di kedua dashboard.

## Handling
- Memastikan informasi `Store ID` tetap muncul dengan aman menggunakan sanitasi `escapeHtml`.
- Mempertahankan kompatibilitas layout visual kartu aktivitas pada viewport desktop maupun layar mobile.
