# Dokumentasi Rilis Update v0.3.5

Perbaikan durasi pause Shopee, timezone, dan keterbacaan informasi status.

**Tanggal Release**: 24 Agustus 2026  
**Jenis Update**: BUGFIX & UX

## Perubahan

1. Durasi pause dari dashboard mitra sekarang diteruskan sampai ke worker.
2. `pause_until` dikonversi ke `pause_end_time` dalam Unix timestamp milidetik
   sesuai payload API Shopee.
3. Pilihan 30 menit tidak lagi menggunakan fallback 1 hari (`1440` menit).
4. Shopee tetap menjadi pihak yang menjadwalkan pembukaan otomatis outlet.
5. Status pause menampilkan sisa waktu, misalnya `Tersisa 2 jam 15 menit`,
   serta waktu target outlet kembali ON.
6. Seluruh waktu tampilan dan log menggunakan timezone WIB/GMT+7.
7. Pecahan detik dan microseconds dihilangkan dari timestamp log dan status.
8. Font status, countdown, riwayat, dan catatan tabel diperbesar serta dibuat
   lebih tebal dengan warna kontras tinggi.

## Komponen

| Komponen | File | Perubahan |
|---|---|---|
| Pause payload | `src/shopee/store_status.py` | Menerima `pause_end_time_ms` eksplisit |
| Pause worker | `main-bot/src/worker.py` | Meneruskan `pause_until` dari database |
| Outlet mapping | `src/backend/db.py`, `src/core/sheets.py` | Menyediakan `pause_until` ke worker |
| Dashboard mitra | `src/backend/templates/user_dashboard.html` | Countdown dan WIB/GMT+7 |
| Admin logs | `src/backend/templates/admin_dashboard.html`, `admin_bot.html` | Timestamp kontras tanpa pecahan detik |
| Log API | `src/backend/db.py` | Format timestamp WIB tanpa microseconds |
| Styling | `src/backend/static/css/styles.css` | Font lebih besar, tebal, dan kontras |
