# v1.7.0

## Whats New

- Menambahkan filter kolom `Status` pada fetch/import Virtual Brand.
- Perilaku filter disamakan dengan import Bot O/C.

## Spesifikasi

- Header `Status`, `Status Import`, dan `Import Status` dikenali secara
  case-insensitive.
- Status aktif yang diterima hanya `Aktif` (case-insensitive), sama seperti
  gate Bot O/C.
- Status selain itu menandai brand `is_active=false`, sehingga tidak muncul
  di dashboard VB dan tidak diproses patrol.
- Kolom status tidak lagi diperlakukan sebagai Store ID.
- Jika status berubah aktif pada fetch berikutnya, brand dipulihkan ke scope.

## Handling

- Fetch data VB dari dashboard admin tetap dilakukan melalui tombol `Fetch
  data`.
- Brand nonaktif tidak dihapus dan relasi outlet tetap dipertahankan agar bisa
  dipulihkan ketika status Sheet kembali aktif.
- Jika Sheet tidak memiliki kolom Status, perilaku kompatibilitas lama tetap
  digunakan: baris dianggap aktif.
