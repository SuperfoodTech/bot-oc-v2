# v1.10.4

## Whats New

- Kartu outlet dashboard admin pada tampilan mobile diselaraskan dengan
  hierarchy informasi mode desktop terbaru.
- Mobile card sekarang menampilkan jam operasional hari ini, status live
  Shopee, action terakhir, periode layanan, dan toggle outlet secara langsung.
- Aksi hapus outlet dipindahkan dari kartu mobile ke panel detail outlet agar
  alur admin mobile lebih rapi dan aman.
- Tab navigasi admin di mobile dirapikan agar label tetap terbaca utuh pada
  layar sempit tanpa terlihat kepotong.

## Spesifikasi

- `src/backend/templates/admin_dashboard.html` merender struktur kartu mobile
  baru dengan blok informasi yang mengikuti tabel dan panel detail desktop.
- `src/backend/static/css/styles.css` menambahkan namespace `admin-mobile-*`
  untuk mengisolasi gaya kartu outlet mobile dari cascade style admin lama.
- `src/backend/templates/admin_dashboard.html` menambahkan tombol
  `Hapus outlet` pada `outlet-detail-actions` agar aksi destruktif tetap
  tersedia setelah dihapus dari daftar kartu mobile.
- `src/backend/static/css/styles.css` menyesuaikan tab navigasi mobile admin
  menjadi grid empat kolom dengan label dua baris yang tetap terbaca di 390px
  sampai 320px.

## Handling

- Mengurangi inkonsistensi visual antara daftar outlet admin di mobile dan
  desktop tanpa mengubah source data yang ditampilkan.
- Menjaga toggle outlet tetap bisa diakses cepat di mobile sambil memperjelas
  status, jadwal, dan audit action terakhir.
- Memindahkan aksi sensitif ke panel detail outlet untuk menurunkan risiko tap
  yang tidak disengaja pada daftar kartu mobile.
- Mengurangi risiko tab `Virtual Brand` dan `Settings` terlihat terlalu mepet
  atau terpotong pada perangkat mobile yang lebih sempit.
