# Release Update 1.19.1 - Virtual Brand Schedule-Aware Toggle Lock & UI Parity

## Whats New

Penyelarasan aturan kendali toggle Virtual Brand (VB) pada `admin_dashboard.html` dengan aturan pagar jadwal (*schedule gate*) yang telah diterapkan pada Dashboard Agency dan Dashboard Mitra. Brand toggle akan secara otomatis terkunci ke posisi non-aktif (*locked off/disabled*) ketika seluruh outlet di bawah brand tersebut berada di luar jadwal operasional (`WAITING_SCHEDULE` / `within_operating_schedule === false`), mencegah kesalahan operasional manual (*human error*) saat toko sedang berada di luar jam operasional.

---

## Spesifikasi

1. **Schedule Lock Evaluation pada Kartu Brand VB (`admin_dashboard.html`)**:
   - Menghitung properti `isScheduleLocked = brandOutlets.length > 0 && brandOutlets.every(...)` berdasarkan status `bot_phase === 'WAITING_SCHEDULE'` atau `within_operating_schedule === false`.
   - Mengaplikasikan class `state-closed` dan atribut `data-schedule-locked="true"` serta `disabled` pada toggle switch brand VB jika seluruh outlet berada di luar jam buka.
   - Menampilkan tooltip informatif: `"Seluruh outlet <brand_name> sedang di luar jadwal operasional Shopee sehingga toggle tidak dapat diaktifkan"`.

2. **Status Pill VB Schedule State**:
   - Jika brand terkunci oleh jadwal operasional, pill status operasional grup menampilkan badge `"Tutup Jadwal"` dengan class status peringatan abu-abu/kuning yang konsisten dengan Agency.

3. **Event Guard pada `handleVbToggleChange`**:
   - Validasi ketat pada event handler klik toggle: jika `isScheduleLocked` aktif atau elemen memiliki atribut `data-schedule-locked="true"`, perubahan state dibatalkan (*reverted*) dan menampilkan pesan notifikasi toast bahwa aksi buka tidak diizinkan di luar jam operasional.

---

## Handling

- **Deployment**:
  - Diterapkan menggunakan standar Zero-Downtime Deployment (`docker compose build web && docker compose up -d --no-deps web`).
  - Container `fm-backend` (`web`) berhasil di-rebuild dan dijalankan ulang tanpa menginterupsi container bot patroli 24/7 (`bot-oc.service` dan `bot-vb.service`).
