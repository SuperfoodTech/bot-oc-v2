# Dokumentasi Rilis Update v0.2.20

Menghapus passcode default dari halaman login mitra.

**Tanggal Release**: 18 Agustus 2026  
**Jenis Update**: Patch keamanan dan UX

## Whats New

1. Field passcode login mitra tidak lagi terisi otomatis.
2. Browser diberi atribut `autocomplete="current-password"` untuk pengisian password yang lebih sesuai.

## Spesifikasi

| Komponen | File | Perubahan |
|---|---|---|
| Login passcode | `src/backend/templates/user_dashboard.html` | Menghapus default `Master@00@` dari input login |

## Handling

1. Mitra harus memasukkan passcode secara manual, kecuali browser mengisinya melalui password manager.
2. Session login yang sudah tersimpan tetap mengikuti mekanisme akses per slug.
3. Deploy perubahan menggunakan:
   ```bash
   docker compose build web
   docker compose up -d --no-deps web
   ```
