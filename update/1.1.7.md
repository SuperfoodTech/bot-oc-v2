# Update v1.1.7

## Whats New

- Log action `ACTION_OPEN` dan `ACTION_CLOSE` kini memiliki pill `Bot` berwarna biru dengan foreground putih dan rounded 30px.
- Dashboard local owner `Yolo` memiliki dummy log open/close untuk pengujian tampilan tanpa menjalankan bot.

## Spesifikasi

- Log tetap difilter menggunakan daftar `store_id` milik owner yang sedang login.
- Dummy hanya aktif pada hostname local dan owner `Yolo`; server tidak menerima dummy.
- Action close menampilkan waktu aksi dan target buka.
- Action open hanya menampilkan waktu saat bot melakukan pembukaan.
- Log dimuat ulang setiap 60 detik selama dashboard mitra aktif agar perubahan dari bot segera tampil.

## Handling

- Data log server tetap berasal dari endpoint `/api/v1/user/history` dan database automation log.
- Polling dashboard hanya membaca endpoint history; tidak menjalankan bot atau mengubah data bot.
- Jika log server action close tidak memiliki target waktu eksplisit, UI menampilkan `sesuai jadwal` tanpa mengarang timestamp.
- Dummy log tidak ditulis ke database dan tidak mengubah status outlet.
