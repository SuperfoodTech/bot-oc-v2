# Dokumentasi Rilis Update v0.3.1

Penonaktifan sementara Google Auth dan penyederhanaan detail outlet.

**Tanggal Release**: 20 Agustus 2026
**Jenis Update**: Patch & Feature Toggle

## Perubahan

1. Google Auth dinonaktifkan sementara melalui konfigurasi `GOOGLE_AUTH_ENABLED=false`.
2. Tombol login Google disembunyikan dari halaman login admin dan dashboard mitra.
3. Field Email Google disembunyikan dari pengaturan admin dan form outlet.
4. Endpoint Google OAuth menolak akses ketika fitur sedang nonaktif.
5. Kode OAuth, model database, dan konfigurasi Google tetap dipertahankan agar dapat diaktifkan kembali.
6. Alasan penangguhan tidak lagi ditampilkan pada detail outlet desktop maupun mobile.

## Teknis

| Komponen | File | Perubahan |
|---|---|---|
| OAuth Toggle | `src/backend/main.py` | Menolak endpoint login dan callback saat Google Auth nonaktif |
| Environment | `.env.example`, `docker-compose.yml` | Menambahkan `GOOGLE_AUTH_ENABLED=false` |
| Admin Login | `src/backend/templates/admin_login.html` | Menyembunyikan opsi login Google |
| Mitra Dashboard | `src/backend/templates/user_dashboard.html` | Menyembunyikan opsi login Google |
| Admin Settings | `src/backend/templates/admin_tab_settings.html` | Menyembunyikan field Email Google |
| Outlet Detail | `src/backend/templates/admin_dashboard.html` | Menghapus tampilan alasan penangguhan |
