# Release Update 1.18.3 - Mitigasi Memory Leak & Pencegahan OOM pada Daemon Bot-OC dan Bot-VB

## Whats New

Implementasi optimasi alokasi memori dan pencegahan Out of Memory (OOM) multi-layer untuk daemon `bot-oc` dan `bot-vb` yang beroperasi 24/7. Pembaruan ini mencakup pembatasan footprint memori browser Chromium/Chrome via flags hemat resource (`imagesEnabled=false`, V8 max heap `512MB`, limit disk & media cache `50MB`, disable features background) serta pembersihan memori Python cyclic reference secara berkala menggunakan `gc.collect()` di setiap akhir siklus loop patroli.

---

## Spesifikasi

1. **Paket Flag Chrome Hemat Memori (`src/core/browser.py` & `main-vb/src/core/browser.py`)**:
   - `--blink-settings=imagesEnabled=false`: Menonaktifkan rendering aset gambar pada instance Chrome Selenium. Mengurangi konsumsi RAM ~150MB–250MB per instance tanpa memengaruhi parsing DOM elemen tombol atau penangkapan XHR/API response toko.
   - `--js-flags=--max-old-space-size=512`: Membatasi alokasi memori V8 JavaScript engine ke 512MB (dari default ~1.4GB) untuk mencegah akumulasi memory leak internal V8 pada single-page application (SPA) Shopee, dengan tetap memberikan ruang aman bagi rendering virtual DOM saat merchant switcher aktif.
   - `--disk-cache-size=52428800` & `--media-cache-size=52428800`: Mengunci ukuran disk cache dan media cache Chrome maksimal 50MB agar tidak membesar seiring berjalannya waktu.
   - `--disable-features=Translate,OptimizationHints,MediaRouter`: Menonaktifkan fitur-fitur background browser yang tidak diperlukan dalam otomasi bot headless.

2. **Pembersihan Siklikal Memori Python (`main-bot/src/daemon.py` & `main-vb/src/daemon.py`)**:
   - Penambahan `gc.collect()` di dalam blok `finally:` pada loop evaluasi utama daemon.
   - Membersihkan referensi objek sirkular (*cyclic reference garbage*), cursor/connection database psycopg yang telah tertutup, parsing tree JSON berukuran besar dari endpoint Shopee API, dan objek traceback exception yang tertinggal di memori.
   - Eksekusi GC dilakukan saat bot memasuki fase idle waiting sehingga memiliki dampak overhead CPU minimal (< 5ms).

3. **Audit Logika & Kepatuhan Arsitektur**:
   - Seluruh perubahan diverifikasi tidak mengubah alur logika bisnis patroli, gate jadwal, sinkronisasi Store ID, maupun pengiriman notifikasi webhook.
   - Branch cadangan `backup-stable` dibuat pada commit stabil sebelumnya (`f005298`) sebagai tuas rollback instan jika diperlukan.

- **Zero-Downtime & Tanpa Interrupsi Bot**:
  - Konfigurasi diterapkan secara aman tanpa mematikan atau menginterupsi container/service `bot-oc` dan `bot-vb` yang sedang aktif bertugas.
- **Kepatuhan Paritas Byte-for-Byte**:
  - `src/core/browser.py` dan `main-vb/src/core/browser.py` terverifikasi 100% identik (*byte-for-byte*, 0 diff).
  - `main-bot/src/worker.py` dan `main-vb/src/worker.py` tetap 100% identik (*byte-for-byte*, 0 diff).
  - `src/core/logger.py` dan `main-vb/src/core/logger.py` tetap 100% identik (*byte-for-byte*, 0 diff).
