# Release Note 1.10.10

## Whats New
- Mengubah container riwayat aktivitas terbaru pada Dashboard Mitra (`.mitra-activity-card .history-list`) menjadi scrollable container internal dengan batas tinggi `max-height: 380px`.
- Menghapus pembatasan `logs.slice(0, 5)` pada rendering client `user_dashboard.html`, sehingga seluruh aktivitas yang dikembalikan oleh API dapat ditinjau langsung tanpa memicu scroll global pada window/body.
- Menambahkan styling scrollbar modern dan halus pada `.history-list` untuk browser berbasis WebKit dan Firefox.

## Spesifikasi
- **Target File**: `src/backend/templates/user_dashboard.html`, `src/backend/static/css/styles.css`, `tests/test_schedule_ui_layout_contract.py`.
- **UI Element**: `.mobile-wrapper.is-dashboard-view .history-list` menggunakan `display: flex`, `flex-direction: column`, `max-height: 380px`, `overflow-y: auto`, `overscroll-behavior: contain`, `scrollbar-width: thin`.
- **Card Padding**: `.mitra-activity-card` disesuaikan menjadi `padding: 18px 18px 12px` agar jarak visual bagian bawah scrollable list tetap rapi.

## Handling
- Menjaga isolasi scroll hanya pada card aktivitas mitra tanpa mengganggu alur scroll utama halaman.
- Memastikan performa rendering tetap ringan saat memuat log aktivitas hingga batas respon API (50 logs).
