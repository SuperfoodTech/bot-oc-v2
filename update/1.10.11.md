# Release Note 1.10.11

## Whats New
- Menambahkan search bar interaktif di dalam dropdown menu filter card untuk **Nama Pemilik**, **Nama Outlet**, dan **Store ID** (serta grup & portal VB).
- Pengguna dapat mengetik kata kunci secara langsung di dalam dropdown untuk menyaring pilihan secara instan secara real-time tanpa perlu menggulir daftar panjang.
- Mendukung navigasi keyboard: tombol `Enter` otomatis memilih item pertama yang cocok dan tombol `Escape` menutup dropdown.
- Menambahkan visual state *empty state* ("Tidak ada hasil ditemukan") saat kata kunci pencarian tidak cocok dengan daftar opsi.

## Spesifikasi
- **Target File**: `src/backend/templates/admin_dashboard.html`, `src/backend/static/css/styles.css`, `tests/test_schedule_ui_layout_contract.py`.
- **UI Element**:
  - Search box: `.custom-filter-search-box`, `.custom-filter-search-icon`, `.custom-filter-search`.
  - Scroll list: `.custom-filter-options-scroll` dengan styling scrollbar WebKit/Firefox.
  - Empty feedback: `.custom-filter-empty`.
- **Behavior**: Dropdown otomatis fokus ke search input saat dibuka (`setTimeout(() => searchInput.focus(), 50)`), dan me-reset kata kunci saat dibuka ulang.

## Handling
- Mencegah event bubbling (`stopPropagation`) pada input pencarian agar dropdown tidak tertutup saat diklik atau diketik.
- Menjaga sinkronisasi dua arah antara custom dropdown UI dan elemen native `<select>` saat reset filter atau pemilihan opsi.
