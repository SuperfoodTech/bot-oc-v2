# Update 1.16.0

## Whats New
- Penyederhanaan interaksi kartu grup Virtual Brand (VB):
  - Tombol chevron expand terpisah (`.vb-expand-button`) dihapus untuk tampilan kartu yang lebih bersih (*clean UI*).
  - **Single click** pada seluruh baris/header kartu grup (`.vb-brand-card-head`) menampilkan/menyembunyikan detail daftar Store ID pada grup tersebut.
  - **Double click** pada header kartu grup menjalankan aksi *Expand All / Collapse All* (membuka semua grup jika ada yang tertutup, atau menutup semua jika seluruhnya terbuka).
  - Navigasi keyboard didukung penuh melalui tombol `Enter` atau `Space` pada header grup yang sedang difokuskan.

## Spesifikasi
- **Frontend Templates & JS**:
  - `src/backend/templates/admin_dashboard.html`:
    - `.vb-brand-card-head` dilengkapi atribut aksesibilitas `role="button"`, `tabindex="0"`, `aria-expanded`, serta event handler `onclick="handleVbBrandCardHeadClick(...)"` dan `onkeydown="handleVbBrandCardHeadKeyDown(...)"`.
    - Fungsi `handleVbBrandCardHeadClick`: Menggunakan timer debounce (~250 ms) untuk membedakan antara *single click* dan *double click*.
    - Fungsi `toggleVbBrandDetail`: Mengubah visibilitas detail grup yang diklik dan memperbarui `aria-expanded` serta set `vbExpandedBrandIds`.
    - Fungsi `toggleAllVbBrands`: Memeriksa apakah ada grup yang masih tertutup; jika ya, membuka seluruh grup (*expand all*), jika tidak, menutup seluruh grup (*collapse all*).
    - Kontrol switch ON/OFF grup (`.vb-brand-toggle` dan `.switch-toggle`) diberi `onclick="event.stopPropagation()"` agar pengubahan status toggle tidak memicu buka/tutup kartu.
- **CSS Styles**:
  - `src/backend/static/css/styles.css`:
    - `.vb-brand-card-head`: Diberi `cursor: pointer`, `user-select: none`, efek transisi latar belakang saat di-hover (`#f8fafc`), dan `focus-visible` outline.
    - Menghapus aturan CSS `.vb-expand-button` yang sudah tidak digunakan.
- **Tests**:
  - `tests/test_schedule_ui_layout_contract.py`: Memverifikasi kehadiran fungsi `handleVbBrandCardHeadClick`, `toggleAllVbBrands`, `toggleVbBrandDetail`, serta ketiadaan elemen `.vb-expand-button`.

## Handling
- Pemisahan *single click* vs *double click* menggunakan mekanisme debounce timer 250 ms mencegah *race condition* atau kedipan UI saat pengguna melakukan double click cepat.
- Zero-downtime deployment diaplikasikan untuk container web tanpa menginterupsi bot patroli dan database.
