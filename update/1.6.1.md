# v1.6.1

> Superseded by v1.6.2. Mode headless kembali menjadi konfigurasi resmi.

## Whats New

- `bot-vb` sekarang dikonfigurasi dengan `HEADLESS=false` pada service
  `bot-vb` di Docker Compose.
- Konfigurasi global `.env` tetap `HEADLESS=true` agar tidak mengubah perilaku
  `bot-oc`.

## Spesifikasi

- Chrome VB tidak menambahkan flag `--headless` ketika konfigurasi bernilai
  `false`.
- Perubahan hanya mengatur mode tampilan browser dan tidak mengubah alur
  patrol, status outlet, atau aksi Shopee.
- Docker membutuhkan X display mapping agar mode GUI dapat digunakan.

## Handling

- Jalankan daemon langsung dari host dengan `HEADLESS=false` jika ingin
  melihat jendela Chrome.
- Jika container gagal start karena tidak memiliki display, ubah environment
  `HEADLESS` container menjadi `true`, lalu recreate service.
