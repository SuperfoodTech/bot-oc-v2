# Release Note 1.13.1

## Whats New
- Memperbaiki tata letak teks subtitle/caption pada halaman login mitra (`#loginSection .mitra-login-copy .card-subtitle`) agar selalu tampil utuh dalam satu baris tanpa pemotongan baris (*no line break / newline*).
- Menghilangkan batasan lebar buatan `max-width: 340px` (desktop) dan `max-width: 304px` (mobile <= 640px) yang sebelumnya memaksa frasa `"Bot Anda."` terpotong ke baris kedua.
- Menerapkan `white-space: nowrap` dan ukuran font adaptif (`clamp(12px, 3.4vw, 14px)`) dengan `max-width: 100%` sehingga teks `"Gunakan kata sandi dari Admin untuk mengakses Bot Anda."` tetap proporsional dan tidak memicu overflow horizontal pada layar perangkat mobile (360px - 430px) maupun layar desktop.
- Memperbarui parameter cache buster stylesheet di template `user_dashboard.html` ke `v=20260909-mitra-login-v62`.

## Spesifikasi
- **Target File**:
  - `src/backend/templates/user_dashboard.html`:
    - Menghilangkan newline pada elemen `<p class="card-subtitle">Gunakan kata sandi dari Admin untuk mengakses Bot Anda.</p>`.
    - Memperbarui versi query string styles.css menjadi `?v=20260909-mitra-login-v62`.

    - Media query `@media (max-width: 640px)`: Mengubah selector `#loginSection .mitra-login-copy .card-subtitle` agar menggunakan `max-width: 100%`, `font-size: clamp(12px, 3.4vw, 14px);`, dan `white-space: nowrap;`.
  - `tests/test_dashboard_label_contract.py`:
    - Menambahkan unit test `test_mitra_login_caption_is_single_line_and_nowrap_contract` untuk memverifikasi teks satu baris utuh dan ketiadaan pembatasan max-width 340px/304px.
