# Release Note 1.12.1

## Whats New
- Mengubah warna latar belakang (*background*) badge status **Aktif** pada kartu Ringkasan Akun Mitra (`#subBadge` pada `.mitra-account-summary`) dari warna merah (`#ed1c24`) menjadi warna hijau standar sukses (`#16a34a`).
- Memberikan konsistensi semantik visual: warna hijau menandakan status akun dan langganan aktif, sedangkan badge `Tidak aktif` tetap menggunakan warna abu-abu netral (`badge-closed`).
- Penyesuaian copywriting dan penamaan antarmuka pada Dashboard Mitra (`user_dashboard.html`):
  - Halaman login mitra: Mengganti indikator menjadi `Bot ShopeeFood`, judul `Masukkan Kata Sandi`, deskripsi `Gunakan kata sandi dari Admin untuk mengakses Bot Anda.`, dan label input `Kata Sandi`.
  - Kartu Ringkasan Akun: Mengubah label `Password:` menjadi `Kata Sandi:` dan label `0 outlet` menjadi `0 Outlet`.
  - Label jam operasional kartu outlet: Mengubah `Jam operasional:` menjadi `Jadwal hari ini:`.
  - Panel drawer jadwal 7 hari: Mengubah judul `Jadwal reguler Shopee` menjadi `Jadwal Operasional`.
  - Status jadwal dan sinkronisasi bot: Mengubah teks fallback di luar jadwal menjadi `Di luar jam operasional`, estimasi buka menjadi `Akan buka pada ...`, serta status kesalahan fetch jadwal menjadi `Ada kesalahan data, harap hubungi Admin`.
