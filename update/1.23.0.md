# Release Update 1.23.0 - Shopee Special Hours Schedule Gate & Priority Evaluation

## Whats New

Integrasi penuh evaluasi Jadwal Khusus Shopee (*Shopee Special Hours*) ke dalam Decision Engine bot patroli (`src/core/decision.py`) dan Runtime State Derivation backend (`src/backend/db.py`). Ketika sebuah outlet memiliki jadwal khusus aktif (misal libur/tutup sepanjang hari atau jam khusus tertentu):
1. Pagar jadwal (*schedule gate*) secara otomatis memprioritaskan Jadwal Khusus di atas Jadwal Reguler.
2. Toggle switch pada dashboard (Admin, Mitra, dan Virtual Brand) otomatis terkunci (*disabled*), berwarna abu-abu (*state-closed*), dan menampilkan label status `Sedang Tutup • Jadwal Khusus`.
3. Bot patroli (`bot-oc` dan `bot-vb`) mematuhi jadwal khusus tutup dan tidak memicu aksi buka (`ACTION_OPEN`) yang sia-sia selama periode jadwal khusus berlangsung.

---

## Spesifikasi

1. **Evaluasi Interval & Tipe Jadwal Khusus (`src/core/decision.py`)**:
   - Menambahkan helper `parse_special_hours_entry`, `get_active_special_hours`, dan `is_within_special_hours_intervals`.
   - Mendukung format timestamp Unix milliseconds (`date_start` dan `date_end`) yang dikonversi secara presisi sesuai timezone outlet.
   - Evaluasi `date_type = 1` (Tutup Sepanjang Hari) langsung mengarahkan target status menjadi `TARGET_CLOSE` dengan alasan `Tutup berdasarkan Jadwal Khusus Shopee (<date_desc>)`.
   - Evaluasi `date_type = 2` (Buka Khusus) mengecek apakah detik hari ini berada di dalam rentang `[start_relative_sec, end_relative_sec]`.
   - Jika waktu saat ini tidak masuk dalam periode jadwal khusus manapun, sistem secara mulus (*seamless fallback*) kembali mengecek jadwal reguler mingguan (`shopee_regular_hours`).

2. **Sinkronisasi Runtime State UI & Akurasi Riwayat Aktivitas (`src/backend/db.py` & Templates)**:
   - `derive_outlet_runtime_state` mengecek keberadaan jadwal khusus aktif untuk menentukan `within_operating_schedule`.
   - Menghasilkan atribut `display_toggle_disabled = True`, `display_toggle_on = False`, dan `display_toggle_reason = 'SPECIAL_HOURS'`.
   - Mengatur `bot_phase = 'WAITING_SCHEDULE'` dengan label `Sedang Tutup • Jadwal Khusus` dan penjelasan detail `display_note`.
   - Query `get_recent_logs` kini menyertakan kolom `al.success` dan `al.error_message`.
   - Fungsi `getHistorySummary` pada dashboard Admin (`admin_dashboard.html`), Mitra (`user_dashboard.html`), dan Brand (`brand_dashboard.html`) membedakan secara akurat antara `"Bot berhasil membuka outlet"` (jika `success=true`) dan `"Bot gagal membuka outlet"` (jika `success=false` / mismatch verifikasi).

3. **Integritas Dataclass & Multi-Service Parity**:
   - `MerchantOutlet` pada `src/core/sheets.py` dan `main-vb/src/core/sheets.py` memuat field `shopee_special_hours`.
   - `fetch_merchant_outlets_from_db` pada `src/backend/db.py` dan `main-vb/src/db.py` meneruskan array `os.shopee_special_hours` ke dalam pipeline evaluasi worker.

---

## Handling

- **Zero-Downtime Web Deployment**:
   - Web backend container (`fm-backend`) di-rebuild dan di-restart menggunakan `docker compose build web && docker compose up -d --no-deps web`.
- **Bot Services Live Reload**:
   - `bot-oc.service` dan `bot-vb.service` di-restart dengan aman dan langsung aktif menjalankan siklus patroli dengan decision engine terbaru.
