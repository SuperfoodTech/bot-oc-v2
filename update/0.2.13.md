# Dokumentasi Rilis Update v0.2.13

Penyederhanaan input passcode pada halaman internal admin.

**Tanggal Release**: 18 Agustus 2026  
**Jenis Update**: Patch UX

## Whats New

1. Kontrol hide/show password di halaman Tambah Mitra dihapus.
2. Passcode dashboard ditampilkan langsung karena halaman hanya dapat diakses admin.
3. Card review juga menampilkan passcode secara langsung agar admin dapat memverifikasi data sebelum simpan.

## Spesifikasi

| Komponen | File | Perubahan |
|---|---|---|
| Input passcode | `src/backend/templates/admin_add_merchant.html` | Menggunakan input text tanpa toggle icon |
| Review passcode | `src/backend/templates/admin_add_merchant.html` | Nilai ditampilkan plain text |

## Handling

1. Halaman tetap dilindungi oleh autentikasi admin.
2. Passcode tidak ditampilkan pada halaman publik atau dashboard mitra.
3. Perubahan hanya menghapus interaksi hide/show dan tidak mengubah payload backend.
4. Deploy perubahan frontend/backend menggunakan:
   ```bash
   docker compose build web
   docker compose up -d --no-deps web
   ```
