# Release Update 1.18.2 - Eliminasi Notifikasi Legacy Error & Isolasi Eksklusif Discord Virtual Brand

## Whats New

Penonaktifan total pengiriman notifikasi error individual/sistem format lama (`❌ Eror Bot Patroli`, field `Modul`, `Platform`, dll.) ke Discord Webhook dari seluruh modul (`src/core/notifier.py`, `src/core/logger.py`, dan `main-vb/src/core/logger.py`). Memastikan saluran Discord Webhook (`DISCORD_WEBHOOK_VB_URL`) **100% eksklusif hanya untuk format Rekap Group Virtual Brand (`send_discord_vb_group_summary`)**, sedangkan seluruh notifikasi event `bot-oc` dialihkan khusus ke WhatsApp Gateway (`bot-wa`).

---

## Spesifikasi

1. **Pembersihan Handler Notifikasi (`src/core/notifier.py`)**:
   - `send_discord_error`: Tidak lagi mengirimkan embed error legacy ke Discord (No-Op untuk Discord). Event error untuk `bot-oc` diteruskan secara eksklusif ke WhatsApp Gateway via `send_wa_webhook_async()` jika parameter `phone` tersedia.
   - `send_discord_success`: Tidak lagi mengirimkan embed individual ke Discord.
   - `send_discord_skipped`: Tidak lagi mengirimkan embed individual ke Discord.
   - `send_discord_vb_group_summary`: Ditetapkan sebagai **satu-satunya fungsi** yang memiliki izin mengirimkan payload embed ke Discord Webhook (mendukung 6 skenario rekap VB Brand).

2. **Koreksi Deteksi Environment (`_is_vb_environment`)**:
   - Memperbaiki `_is_vb_environment()` pada `src/core/notifier.py` agar hanya mengecek `is_vb` atau `VB_SHOPEE_USERNAME`. Keberadaan `DISCORD_WEBHOOK_VB_URL` pada `.env` tidak lagi menyebabkan `bot-oc` salah dikenali sebagai VB.

3. **Deaktivasi Logger Discord Hook (`logger.py`)**:
   - `DiscordWebhookHandler` pada `src/core/logger.py` dan `main-vb/src/core/logger.py` dinonaktifkan (No-Op pada method `emit`) sehingga log internal `logger.error(...)` tidak lagi memicu pengiriman pesan error acak ke Discord.

---

## Handling

- **Zero-Downtime & Zero-Interruption**:
  - Seluruh perbaikan dieksekusi secara dinamis tanpa me-restart service `bot-oc.service` maupun `bot-vb.service`, sehingga browser Selenium Chrome dan proses background PID tetap berjalan kontinu 24/7.
- **Kepatuhan Paritas**:
  - File `main-bot/src/worker.py` dan `main-vb/src/worker.py` tetap 100% identik (*byte-for-byte*, 0 diff).
  - File `src/core/browser.py` dan `main-vb/src/core/browser.py` tetap 100% identik (*byte-for-byte*, 0 diff).
  - File `src/core/logger.py` dan `main-vb/src/core/logger.py` tetap 100% identik (*byte-for-byte*, 0 diff).
