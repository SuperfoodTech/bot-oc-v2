# Release Note 1.11.1

## Whats New
- Mengembalikan dan mengoptimalkan tata letak `.outlet-filter-toolbar` pada Dashboard Admin menjadi **1 baris sejajar** secara penuh (`repeat(6, minmax(0, 1fr)) auto`) untuk seluruh mode desktop dan laptop.
- Mengatasi tuntas bug visual overlapping antardropdown (terutama antara filter `Subscription` dan `Paket`) dengan:
  - Mengubah `.custom-filter-trigger` menjadi `display: block`, `box-sizing: border-box`, `min-width: 0`, `max-width: 100%`, dan `overflow: hidden; text-overflow: ellipsis;` sehingga elemen pemicu dropdown tidak akan meluap (*overflow*) keluar dari grid track kolomnya.
  - Menetapkan `min-width: 0` dan `box-sizing: border-box` pada `.filter-field` dan `.custom-filter`.
  - Mengoptimalkan padding horizontal dropdown dari `47px` (`padding: 0 34px 0 13px`) menjadi `33px` (`padding: 0 24px 0 9px`), serta memperkecil ukuran ikon chevron menjadi `12px` di posisi `right 8px center`.
  - Menyesuaikan gap antarkolom menjadi `8px` dan padding kartu filter menjadi `14px 14px`, memberikan tambahan ruang horizontal sebesar ~90px sehingga teks label panjang seperti `"Semua subscription"` dan `"Semua paket"` tetap tampil penuh tanpa terpotong pada layar laptop standar 1366px.
  - Menjadikan tombol `Reset filter` lebih ringkas (`padding: 0 10px`, icon 13px) agar memaksimalkan lebar bagi ke-6 dropdown filter.
