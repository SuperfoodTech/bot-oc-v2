# Release Note 1.11.0

## Whats New
- Menyederhanakan tata letak tabel outlet pada Dashboard Admin dari 9 kolom menjadi 7 kolom dengan meniadakan kolom **Status**, **Action**, dan **Periode Layanan** untuk mengeliminasi redundansi visual.
- Menambahkan kolom baru **Link** berisi tautan langsung ke outlet ShopeeFood dari sudut pandang pelanggan (Customer POV) menggunakan universal link `https://shopee.co.id/universal-link/now-food/shop/{storeId}` lengkap dengan ikon ShopeeFood.
- Menyederhanakan tampilan pada kolom **Jam Operasional** dengan menghapus nama hari ("hari apa hari ini"), sehingga hanya menampilkan jam operasional dan zona waktu (misalnya `08:00 - 22:00 WIB` atau `Tutup`).
- Menerapkan mekanisme **Toggle 3-State** yang merefleksikan status outlet ShopeeFood secara langsung:
  - **Open**: Posisi toggle di kanan dengan warna hijau (`#16a34a`), menandakan outlet sedang buka dan menerima pesanan.
  - **Paused**: Posisi toggle di kiri dengan warna merah (`#dc2626`), menandakan outlet sedang tutup sementara / pause dan dapat diklik langsung untuk membuka kembali outlet.
  - **Closed**: Posisi toggle di kiri dengan warna abu-abu (`#cbd5e1`) dan status disabled, menandakan outlet tutup di luar jadwal operasional atau dinonaktifkan admin.
- Menambahkan **Tooltip Detail Komprehensif** pada setiap state toggle (desktop & mobile) yang memuat status outlet saat ini, live status Shopee, rincian kondisi/alasan penguncian saat disable (misal: di luar jam operasional, dinonaktifkan admin, atau menunggu fetch jadwal), serta opsi tindakan yang tersedia.
- Membersihkan tampilan **Modal Pause** di Dashboard Admin dan Dashboard Mitra (User) dengan menghapus info duplikat di sebelah kanan radio card (seperti teks `30 mnt`, `1 jam`, dan timestamp `Kam 00:00 WIB`) agar tampilan opsi durasi lebih bersih dan fokus pada label pilihan.

## Handling
- Mencegah event bubbling (`event.stopPropagation()`) pada tautan ShopeeFood agar klik tautan tidak memicu pembukaan panel samping Detail Outlet.
- Memastikan modal pause durasi tetap muncul saat admin mematikan outlet dari kondisi Open (hijau ke kiri), dan eksekusi langsung menyalakan outlet saat diklik dari kondisi Paused (merah ke kanan).
- Menjaga kepatuhan aturan UI Mobile pada `AGENTS.md`: kartu mobile tetap mempertahankan identitas outlet, jam operasional, action terakhir, periode layanan, serta menyertakan tombol tautan ShopeeFood dan toggle 3-state yang sinkron.
