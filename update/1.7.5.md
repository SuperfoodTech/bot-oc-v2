# v1.7.5

## Whats New

- Menyamakan pembacaan status live outlet pada `bot-vb` dengan `bot-oc`.

## Spesifikasi

- `pause_info.pause_start_time > 0` menghasilkan status `PAUSE`.
- `status_str == OPEN` menghasilkan status `ON`.
- Status non-OPEN tanpa pause aktif menghasilkan status `CLOSED`.
- Alur tetap menggunakan fetch status, komparasi target, XHR action, lalu
  fetch ulang untuk verifikasi.

## Handling

- Status `CLOSED` tidak dianggap sebagai pause aktif.
- Tidak ada perubahan pada credential dan sumber data VB.
- Tidak ada bot atau request Shopee yang dijalankan dalam validasi ini.
