# Dokumentasi Rilis Update v0.2.2

Penyesuaian dan Perbaikan Stabilitas Agency Churn Bot (`fm-agency`): Sinkronisasi penuh browser core, perbaikan penanganan merchant tidak terdaftar (*graceful skip* & status retention), serta penyeragaman navigasi Single-Page Dashboard untuk Tab Logs.

---

## Whats New

1. **Sinkronisasi 1:1 `src/agency/browser.py`**:
   - Menyelaraskan seluruh logika Selenium browser dari `src/core/browser.py` untuk container `fm-agency`.
   - Menggunakan kredensial khusus `allvbadmin` (`src/data/credentials allvbadmin.json`) dan profile terisolasi (`src/data/chrome_profile`).
   - Menyelesaikan masalah pembacaan kredensial sehingga input login username dipastikan menggunakan **`allvbadmin`**.

2. **Penanganan Merchant Tidak Terdaftar (*Graceful Skip* & Preservasi Status)**:
   - Jika suatu outlet/merchant tidak terdaftar atau belum di-invite ke akun Shopee ini, bot tidak melempar exception unhandled yang menghentikan daemon.
   - **Logika Preservasi Status**: Membedakan *Transient Driver Error* (koneksi terputus/timeout) vs *Confirmed Missing Merchant*. Jika sebelumnya outlet sudah pernah berstatus `OPEN`/`CLOSED`, transient error **TIDAK AKAN menimpa status valid tersebut**.
   - Jika merchant terkonfirmasi benar-benar tidak terdaftar setelah 3x scan dropdown, status baru di-update menjadi `NOT_FOUND`.

3. **Kolom "Terakhir Dicek" di Dashboard Agency**:
   - Menambahkan kolom timestamp **Terakhir Dicek** pada tabel Churn Bot di `src/backend/templates/admin_tab_agency.html`.
   - Menampilkan jam dan menit terkini (misal `11:20:11 WIB`) kapan status outlet tersebut terakhir diperiksa bot.

4. **Penyesuaian Tab Logs (`?tab=logs`)**:
   - Menamai ulang tab navigasi dari **Bot** menjadi **Logs** (`.../admin/dashboard?tab=logs`).
   - Tab Logs menampilkan tampilan visual lengkap Monitor Bot Patroli (kartu monitor, status real-time, statistik siklus, dan tabel log & action) secara langsung tanpa reload halaman.
   - Route `/admin/bot` dan `/admin/logs` otomatis me-redirect ke `/admin/dashboard?tab=logs`.

5. **Pembersihan Underline & Penyeragaman Styling Tab**:
   - Menghapus total efek underline garis bawah pada seluruh tautan tab navigasi via CSS `text-decoration: none !important`.
   - Menyelaraskan font, ukuran (`13px`/`14px`), font-weight (`600`), dan warna aktif secara persis untuk keempat tab di seluruh halaman.
   - Menghapus badge counter `0` pada tab Churn Bot dan indikator `Patroli Offline` yang lama.

## Handling & Deployment

1. **Rebuild Container Backend (`fm-backend`)**:
   Dijalankan dengan Zero-Downtime Deployment command tanpa menginterupsi container bot:
   ```bash
   docker compose build web
   docker compose up -d --no-deps web
   ```

2. **Verifikasi Service Status**:
   ```bash
   docker ps --filter "name=fm-"
   ```
