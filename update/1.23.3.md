# Release Update 1.23.3 - Dynamic Agency Summary Cards on Filter Change

## Whats New

Kartu ringkasan metrik pada tab Agency (`admin_dashboard.html` / `admin_tab_operasional.html`):
1. **Total Outlet (`#metricTotal`)**
2. **Sedang Buka (`#metricOpen`)**
3. **Sedang Tutup (`#metricClosed`)**

Kini diperbarui secara **dinamis dan instan** mengikuti filter aktif (pencarian nama outlet, nama pemilik, Store ID, dan filter status), memberikan parity perilaku yang identik dengan Tab Virtual Brand (VB).

---

## Spesifikasi

1. **Fungsi Dinamis `updateAgencyStatCards(stores)` (`admin_dashboard.html`)**:
   - Menghitung jumlah total outlet, status buka (`open`), dan status tutup (`closed`) berdasarkan subset data toko yang sedang aktif setelah disaring filter (`baseFiltered`).
   - Dipanggil di dalam `filterTable()` setiap kali terjadi perubahan input pencarian header, select filter pemilik, select filter outlet, select filter Store ID, select filter status, maupun saat reset filter.

2. **Integritas Count Tab & Lifecycle**:
   - `updateMetrics(stores)` memanggil `updateAgencyStatCards(stores)` saat inisialisasi awal maupun saat pembaruan data via Server-Sent Events (SSE) / Polling.
   - Saat filter di-reset (`resetOutletFilters()`), kartu metrik secara otomatis kembali merefleksikan seluruh outlet (`allStores`).

---

## Handling

- **Zero-Downtime Deployment**:
  - Web container `fm-backend` diperbarui dengan `docker compose build web && docker compose up -d --no-deps web`.
  - Service bot patroli (`fm-bot`, `bot-vb`, `bot-oc`) tetap aktif 24/7 tanpa interupsi.
