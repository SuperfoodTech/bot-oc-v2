# v1.9.0

## Whats New

- Worker Virtual Brand menggunakan worker bot-OC yang sama secara byte-for-byte.
- Core VB yang dipakai untuk keputusan, parsing data, browser, dan XHR Shopee
  disamakan dengan core bot-OC.
- VB tetap memiliki entry point logger sendiri agar import worker tetap valid.

## Spesifikasi

- Target `ON/OFF` worker VB dibaca dari `vb_brands.applied_status`, yaitu state
  toggle yang berasal dari dashboard admin tab Virtual Brand.
- Query worker hanya mengambil outlet yang terhubung ke brand VB aktif dan
  outlet aktif.
- `pause_until` dari brand diterjemahkan oleh worker yang sama ke
  `pause_end_time` Unix timestamp milliseconds untuk payload pause Shopee.
- Schedule reguler dan status aktual Shopee tetap diambil melalui XHR worker
  dan disimpan ke `outlet_states`.
- Log action VB disimpan dengan `mode='VB'` serta relasi brand jika tersedia;
  log bot-OC tidak diubah.

## Handling

- Spreadsheet tetap menjadi sumber import/sinkronisasi brand, bukan sumber
  runtime patrol.
- Brand `Nonaktif` atau yang tidak lagi masuk hasil import tidak masuk scope
  worker VB.
- Status Shopee `CLOSED` dipersistenkan sebagai `OFF` karena constraint
  `outlet_states.shopee_actual_status` tidak menerima nilai `CLOSED`; worker
  tetap memakai status live untuk evaluasi pada cycle berjalan.
- `main-bot/src/worker.py` tidak dimodifikasi.
- Validasi dilakukan dengan perbandingan byte file dan `compileall`; daemon
  tidak dijalankan.
