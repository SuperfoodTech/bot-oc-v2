# v1.7.4

## Whats New

- `bot-vb` sekarang mengikuti kontrak durasi pause `bot-oc`.

## Spesifikasi

- `pause_until` brand dikonversi ke Unix timestamp milliseconds dengan
  timezone Asia/Jakarta jika nilai database tidak memiliki timezone.
- Payload pause VB mengirim `pause_start_time` dari waktu browser Shopee dan
  `pause_end_time` dari target yang dipilih, tanpa fractional milliseconds.
- Fallback durasi 1.440 menit hanya berlaku jika tidak ada target pause,
  bukan untuk pause timed dari dashboard.
- Aksi pause menggunakan XHR langsung, sehingga klik UI tidak dapat
  mengganti target waktu custom.

## Handling

- Status pending brand diterapkan lebih dahulu pada awal giliran brand.
- Setelah penerapan, nilai `pause_until` terbaru dipakai untuk payload outlet
  pada putaran yang sama.
- Setelah aksi, status outlet tetap di-fetch ulang untuk validasi seperti
  `bot-oc`.
