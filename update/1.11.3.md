# Release Note 1.11.3

## Whats New
- Menghapus badge jumlah "outlet" di atas daftar kartu outlet mitra (`.section-heading.mitra-section-heading`), sehingga tidak ada lagi teks jumlah outlet (seperti "4 outlet") yang mengambang di atas kartu outlet. Jumlah outlet tetap terjaga di dalam kartu ringkasan akun mitra (`#accountOutletCount` pada `.mitra-account-meta`).
- Menghapus tulisan "Buka otomatis" beserta seluruh container baris toggle lama (`.mitra-outlet-toggle-row`).
- Menghapus pill badge status Shopee ("Sedang Buka", "Sedang Tutup • Di luar jadwal", dll.) yang berada di sebelah kanan nama outlet (`.mitra-outlet-side`) karena informasi status operasional telah disajikan lengkap pada baris meta di bawahnya.
- Memindahkan switch toggle ke posisi atas kartu outlet di sebelah kanan nama outlet (di bawah Store ID, menggantikan posisi pill badge).
- Mengimplementasikan 3-state toggle pada kartu outlet mitra yang identik dengan Admin Dashboard di agency:
  - **State OPEN** (Kanan, Hijau `#16a34a`): Outlet sedang buka dan aktif mengikuti jam operasional. Klik untuk tutup sementara (pause).
  - **State PAUSED** (Kiri, Merah `#dc2626`): Outlet sedang dalam masa jeda / tutup sementara (pause). Klik untuk membuka outlet sekarang.
  - **State CLOSED** (Kiri, Abu-abu disable `#cbd5e1`): Outlet dinonaktifkan admin atau berada di luar jadwal operasional (toggle terkunci / disabled).
- Standardisasi konsistensi format jam/waktu di seluruh dashboard: Mengubah format titik (`08.00-21.00`) menjadi titik dua (`:`) standar waktu internasional (`08:00-21:00`), baik pada jam operasional ringkasan hari ini maupun drawer jadwal 7 hari.

## Handling
- Mengganti fungsi `formatScheduleRange` dan `parseScheduleRange` agar menormalisasi format titik `.` menjadi titik dua `:` pada string jadwal.
- Menyembunyikan `.mitra-section-heading` tanpa memicu error null reference pada skrip client saat update data total outlet.
- Memindahkan elemen toggle ke dalam `.mitra-outlet-side` dengan kelas `state-${toggleState}` (`open`, `paused`, `closed`) dan tooltip dinamis.
- Menyesuaikan `.mitra-outlet-meta` dengan `padding-top: 14px; border-top: 1px solid #edf2f7;` untuk pemisah visual yang bersih dan konsisten.
- Memastikan event klik toggle tetap memicu flow pause modal saat `state-open` dan resume confirmation modal saat `state-paused`, serta memblokir aksi dengan toast error saat `state-closed`.
