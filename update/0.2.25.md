# Dokumentasi Rilis Update v0.2.25

Mengembalikan emphasis visual pada action `Tutup sementara`.

**Tanggal Release**: 19 Agustus 2026  
**Jenis Update**: Patch UX

## Whats New

1. Tombol `Tutup sementara` kembali menggunakan warna merah/danger.
2. Card outlet tetap menggunakan surface putih netral.
3. Hover state tombol menggunakan merah yang lebih gelap.

## Spesifikasi

| Komponen | File | Perubahan |
|---|---|---|
| Operational action | `src/backend/static/css/styles.css` | Mengembalikan warna danger untuk tombol `Tutup sementara` |

## Handling

1. Warna merah menandai action yang berdampak pada status operasional outlet.
2. Background card tetap netral agar halaman tidak kembali menjadi pastel.
3. Deploy perubahan menggunakan:
   ```bash
   docker compose build web
   docker compose up -d --no-deps web
   ```
