# Release Note 1.13.2

## Whats New
- Menghapus prefix `"Mitra "` pada nama pemilik akun di kartu Ringkasan Akun Dashboard Mitra (`.mitra-account-summary #mitraName`), sehingga menampilkan nama pemilik akun secara langsung (misal: `"Amir"` alih-alih `"Mitra Amir"`).
- Mengubah kapitalisasi teks jumlah outlet pada fungsi `formatOutletCount` di Dashboard Mitra dari format huruf kecil (`"${safeTotal} outlet"`) menjadi huruf kapital (`"${safeTotal} Outlet"`, misal: `"4 Outlet"`).

## Spesifikasi
- **Target File**:
  - `src/backend/templates/user_dashboard.html`:
    - Mengubah penugasan teks nama pemilik di `doLogin`: `document.getElementById('mitraName').textContent = data.nama_pemilik || '';`.
    - Mengubah fungsi `formatOutletCount(total)`: mengembalikan `${safeTotal} Outlet`.
  - `tests/test_dashboard_label_contract.py`:
    - Menambahkan unit test `test_mitra_account_summary_name_and_outlet_capitalization_contract` untuk memverifikasi ketiadaan prefix `"Mitra "` dan penggunaan huruf kapital `"Outlet"`.

## Handling
- Menjaga konsistensi tampilan informasi pada kartu Ringkasan Akun Dashboard Mitra baik pada saat rendering awal maupun setelah autentikasi data API.
