# Dokumentasi Rilis Update v0.2.28

Integrasi import outlet dari Google Sheet dan penyederhanaan dashboard admin.

**Tanggal Release**: 20 Agustus 2026
**Jenis Update**: Feature, Cleanup & Fix Deployment

## What's New

1. Dashboard admin dapat melakukan **Fetch dari Sheet** secara manual melalui CSV Google Sheet.
2. Hanya baris dengan `Status = Aktif` yang di-import atau di-update ke database.
3. `Store ID` digunakan sebagai kunci unik agar proses fetch idempotent dan tidak membuat duplikat.
4. Baris dengan status `Nonaktif` menyembunyikan outlet dari dashboard dan proses bot.
5. Delete dari dashboard melakukan write-back ke Google Sheet dengan mengubah status menjadi `Nonaktif` melalui Google Apps Script.
6. Outlet baru dari Sheet menggunakan status operasional default `ON`.
7. Header data utama tabel dashboard disamakan dengan Google Sheet:
   - `Nama Pemilik`
   - `Merchant Name`
   - `Store ID`
   - `Nama Panjang Outlet`
   - `Tanggal Berakhir Layanan`
8. Empat kartu statistik dashboard dihapus; status bot ditampilkan sebagai badge sederhana.
9. Fitur dan container Churn Bot dihapus dari aplikasi.

## Perbaikan

1. Importer Sheet dipindahkan ke `src/core/import_sheet.py` agar tersedia di runtime Docker.
2. Endpoint Fetch tidak lagi mengimpor modul dari folder `scripts` yang tidak disalin ke image production.
3. Status operasional outlet, pause, suspend, dan status Shopee yang sudah tersimpan tidak ditimpa oleh proses fetch.

## Komponen

| Komponen | File | Perubahan |
|---|---|---|
| Sheet CSV Parser | `src/core/sheets.py` | Parsing layout kolom A–L terbaru |
| Sheet Importer | `src/core/import_sheet.py` | Upsert berdasarkan Store ID dan validasi duplikat |
| Apps Script Client | `src/backend/apps_script.py` | Write-back status Nonaktif ke Sheet |
| Apps Script | `scripts/google_sheets_webapp.gs` | Endpoint deactivate berdasarkan Store ID |
| Admin API | `src/backend/main.py` | Fetch manual dan delete dengan write-back |
| Admin Dashboard | `src/backend/templates/admin_dashboard.html` | Tombol Fetch dan aksi admin yang disederhanakan |
| Outlet Table | `src/backend/templates/admin_tab_operasional.html` | Header mengikuti nama kolom Sheet |

## Deployment

Untuk update web/backend tanpa menghentikan bot dan database:

```bash
docker compose build web
docker compose up -d --no-deps web
```

Pastikan environment berikut tersedia di `.env`:

```env
GOOGLE_SHEETS_CSV_URL=<published-google-sheet-csv-url>
GOOGLE_SHEETS_APPS_SCRIPT_URL=<apps-script-web-app-url>
GOOGLE_SHEETS_APPS_SCRIPT_TOKEN=<webhook-token>
```
