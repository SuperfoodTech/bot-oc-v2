# Release Update 1.19.2 - UI Toggle Visual State Refinement & Label Removal

## Whats New

Penyederhanaan dan standardisasi visual switch toggle status pada Dashboard Admin (Agency & Virtual Brand) dan Dashboard Mitra. Menghapus seluruh teks label samping/internal (`"Luar Jadwal"`, `"OFF"`) saat toggle dalam kondisi mati/terkunci, sehingga switch toggle tampil bersih (*clean UI*) dengan representasi 3-state visual:
- **Di Luar Jadwal Operasional**: Toggle terkunci di posisi kiri, berlatar abu-abu (*gray* / `state-closed`), status `disabled`, tanpa label teks.
- **Tutup / Pause Manual (Dalam Jam Operasional)**: Toggle di posisi kiri, berlatar merah (*red* / `state-paused`), tanpa label teks.
- **Buka / Aktif (Dalam Jam Operasional)**: Toggle di posisi kanan, berlatar hijau (*green* / `state-open`), tanpa label teks.

---

## Spesifikasi

1. **Penghapusan Label Teks Toggle VB (`admin_dashboard.html`)**:
   - Menghapus rendering elemen `<span class="vb-control-label">` (`Luar Jadwal` / `OFF`) pada kontainer `.vb-control`.
   - Tooltip hover (`title`) tetap menyediakan detail status informatif saat kursor diarahkan ke toggle switch.

2. **Konsistensi Visual 3-State Toggle (`styles.css`)**:
   - `state-open`: Slider hijau (`#16a34a`), knob di kanan (`translateX(16px)`).
   - `state-paused`: Slider merah (`#dc2626`), knob di kiri (`translateX(0)`).
   - `state-closed`: Slider abu-abu (`#cbd5e1` / `#4b5563` dark mode), knob di kiri (`translateX(0)`), kursor `not-allowed`.
   - Menghapus aturan spesifisitas usang pada `.vb-control .switch-toggle` agar mengadopsi ukuran standar 36px x 20px secara presisi.
