# Release Update 1.20.0 - Virtual Brand Dedicated Dashboard & Link Brand Integration

## Whats New

Peluncuran fitur **Dashboard Publik Khusus Virtual Brand (VB)** via direct slug URL (`/brand/{slug}`) yang dapat diakses langsung oleh PIC Brand tanpa memerlukan form login password. Serta penggantian kolom *"Jadwal Khusus"* pada tabel outlet Virtual Brand di Admin Dashboard menjadi kolom **"Link Brand"** yang terhubung langsung ke dashboard masing-masing brand.

---

## Spesifikasi

1. **Dashboard Publik Virtual Brand (`/brand/{slug}`)**:
   - **Direct Access**: Akses instan tanpa halaman login melalui slug nama brand (misal: `/brand/katsu-geprek`) maupun UUID brand.
   - **Brand Hero Card**:
     - Menampilkan nama brand utama.
     - Switch toggle 3-state tanpa label teks (Buka = Hijau, Tutup Manual = Merah, Luar Jadwal = Abu-abu disabled).
     - 3 Metrik Status Live Badges: **Live Buka** (hijau), **Perlu Cek** (kuning/merah), dan **Live Tutup** (abu-abu/merah).
     - Tombol **"Lihat Jadwal Operasional"** yang membuka drawer bottom sheet jadwal.
   - **Daftar Outlet (Collapsible Accordion)**:
     - Header `Daftar Outlet (N Outlet)` dengan tombol chevron panah yang berotasi halus saat di-expand/collapse.
     - Konten 2 kolom ringkas:
       - **Kolom 1: Nama Outlet** (Nama listing, Portal, dan Store ID).
       - **Kolom 2: Status** (Status live Shopee / status bot).
     - Tanpa tombol link ShopeeFood pada dashboard brand publik.
   - **Bottom Sheet Jadwal Operasional**:
     - Drawer dari bawah layar yang menampilkan jam operasional reguler 7 hari (Senin–Minggu dengan highlight hari ini) serta jadwal khusus dari store ID pertama yang valid di bawah brand tersebut.
   - **Riwayat Aktivitas Terakhir**:
     - Menampilkan riwayat log audit aktivitas buka/tutup bot untuk outlet-outlet brand terkait.

2. **Kolom Link Brand pada Admin Dashboard (`admin_dashboard.html`)**:
   - Menggantikan kolom *"Jadwal Khusus"* (kolom ke-6) pada `.vb-store-table` menjadi kolom **"Link Brand"**.
   - Setiap baris outlet menampilkan tautan langsung menuju `/brand/{slug}` untuk memudahkan admin membagikan dashboard ke PIC brand.

3. **Public API Endpoints (`main.py` & `vb.py`)**:
   - `GET /brand/{slug}`: Route halaman template `brand_dashboard.html`.
   - `GET /api/v1/brand/{slug}`: Mengembalikan data detail brand, metrik status live, jadwal store pertama, daftar outlet 2 kolom, dan log aktivitas.
   - `POST /api/v1/brand/{slug}/toggle`: Mengubah status brand (buka/pause) secara instan dan memicu Express Lane worker bot patroli.

## Handling

- **Deployment**:
  - Diterapkan menggunakan standar Zero-Downtime Deployment (`docker compose build web && docker compose up -d --no-deps web`).
  - Container `fm-backend` (`web`) aktif kembali dengan status *healthy*.
  - Container dan service bot patroli 24/7 (`bot-oc.service` dan `bot-vb.service`) tetap aktif berjalan tanpa gangguan session.
