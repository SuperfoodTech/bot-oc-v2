# Release Update 1.22.2 - Atomic Per-Cycle Discord Notification Aggregation for Virtual Brand

## Whats New

Penyempurnaan mekanisme pengiriman notifikasi Discord Virtual Brand (`send_discord_vb_group_summary`) untuk brand multi-portal. Notifikasi rekap grup VB kini dikirimkan secara atomik (*single consolidated notification*) di akhir siklus daemon setelah seluruh portal selesai dieksekusi, mengeliminasi pengiriman laporan bertahap ("mencicil") dan false alert `Sebagian Berhasil`.

---

## Spesifikasi

1. **Pemisahan Trigger Flush Notifikasi**:
   - Menghapus pemanggilan premature `_flush_pending_brand_notifications()` dari dalam handler `record_log(store_id="SYSTEM")` pada `main-vb/src/db.py`.
   - Mengekspos fungsi publik `flush_pending_brand_notifications()` pada `main-vb/src/db.py`.
   - Sinyal `store_id == "SYSTEM"` dari worker per-portal kini diperlakukan sebagai catatan log internal tanpa memicu pengiriman webhook ke Discord.

2. **Agregasi Atomik di Akhir Siklus Daemon (`daemon.py`)**:
   - Pemanggilan `db.flush_pending_brand_notifications()` ditempatkan secara terpusat di akhir putaran siklus evaluasi daemon pada `main-vb/src/daemon.py` setelah seluruh antrean portal selesai dievaluasi dan dieksekusi.
   - Seluruh outlet di bawah brand (baik dari Portal 1, Portal 2, maupun Portal N) telah selesai diproses dan status post-action-nya telah tercatat di database sebelum rekapitulasi Discord dievaluasi.

3. **Integritas Worker Parity**:
   - File `main-vb/src/worker.py` tetap 100% identik *byte-for-byte* dengan `main-bot/src/worker.py`. Seluruh perbedaan perilaku notifikasi diisolasi pada adapter `main-vb/src/db.py` dan runner `main-vb/src/daemon.py`.

---

## Handling

- **Zero-Downtime Live Reload**:
   - Perubahan berada pada runtime layer Python daemon dan adapter DB yang tidak memerlukan migrasi skema database baru atau penambahan dependensi package.
- **Deduplikasi Webhook**:
   - Pengiriman rekapitulasi multi-portal menghasilkan 1 notifikasi utuh (misal `🔴 VB GROUP BERHASIL DITUTUP BOT` untuk seluruh outlet) dan mencegah duplikasi payload di Discord channel.
