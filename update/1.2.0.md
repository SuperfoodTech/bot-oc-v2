# Update v1.2.0

## Whats New

- Menambahkan jadwal reguler Shopee read-only pada setiap card outlet.
- Jadwal dibuka melalui arrow merah tebal.
- Worker mengambil jadwal dari endpoint XHR `/api/seller/store/regular-hours` menggunakan session Shopee yang sudah aktif.

## Spesifikasi

- Data XHR dinormalisasi dari `weekday`, `config_enabled`, dan `intervals` berbasis detik sejak tengah malam.
- Jadwal disimpan terpisah pada `outlet_states.shopee_regular_hours` agar tidak menimpa jadwal decision engine.
- Local owner `Yolo` menggunakan response dummy `DOCS/reguler-hours-response.json`.
- Tampilan jadwal hanya read-only dan menampilkan `Tutup` untuk konfigurasi nonaktif atau interval `0 - 0`.

## Handling

- Jadwal server berasal dari hasil fetch worker dan dipisahkan berdasarkan `store_id`.
- Bot tidak dijalankan dalam perubahan ini.
- Migration `007_shopee_regular_hours.sql` menambahkan kolom JSONB untuk jadwal hasil XHR.
