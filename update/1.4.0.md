# Update v1.4.0

## Whats New

- Dashboard admin desktop memiliki tombol `Lihat jadwal` pada detail outlet.
- Dashboard admin mobile memiliki tombol `Lihat jadwal` di samping `Hapus akun`.
- Jadwal mobile ditampilkan sebagai bottom sheet yang muncul dari bawah.
- Bottom sheet memiliki handle untuk ditarik dan tombol `X` untuk menutup.

## Spesifikasi

- Data jadwal dipilih per `store_id` dari `shopee_regular_hours`.
- Panel desktop menampilkan jadwal di area detail outlet.
- Bottom sheet mobile hanya aktif pada viewport mobile.
- Tampilan jadwal bersifat informasi dan tidak menyediakan kontrol edit.

## Handling

- Menarik sheet lebih dari 110px ke bawah akan menutupnya.
- Tombol `X` menutup sheet tanpa mengubah data.
- Body halaman dikunci selama sheet terbuka.
