# Release Note 1.12.0

## Whats New
- Menambahkan kolom baru **Link Mitra** pada tabel operasional outlet Dashboard Admin (`#adminTable`), diposisikan tepat di sebelah kanan kolom **Link** ShopeeFood.
- Memindahkan CTA tombol dari dalam panel drawer detail outlet (`outletDetailPanel`) langsung ke tabel pada kolom baru **Link Mitra** (`.admin-table-mitra-link`), sehingga admin dapat langsung mengakses dashboard mitra tanpa perlu membuka drawer terlebih dahulu.
- Tombol tautan **Link Mitra** tampil bersih dan elegan dengan teks "Link Mitra" serta ikon tautan eksternal standar, tanpa menyertakan logo ShopeeFood.
- Mengintegrasikan tautan cepat **Link Mitra** pada kartu outlet mode mobile (`.admin-mobile-shopeefood-action`) agar pengguna mobile tetap memiliki akses langsung yang setara.
- Menghapus elemen aksi `.outlet-detail-mitra-action` dari panel drawer samping detail outlet.

## Spesifikasi
- **Target File**:
  - `src/backend/templates/admin_tab_operasional.html`
  - `src/backend/templates/admin_dashboard.html`
  - `src/backend/static/css/styles.css`
  - `tests/test_schedule_ui_layout_contract.py`
- **UI Elements & Styling**:
  - Kolom Header: `<th>Link Mitra</th>` di antara `<th>Link</th>` dan `<th>Toggle</th>`.
  - Class Tautan: `.admin-table-mitra-link` dengan warna brand merah FoodMaster (`#be1a1a` / dark `#f87171`), ikon eksternal SVG 12px, hover background lembut, tanpa logo Shopee.
  - Distribusi Lebar Kolom: Penyesuaian lebar 8 kolom (Owner: 12%, Merchant: 13%, Store ID: 9%, Outlet: 18%, Jam Operasional: 14%, Link: 13%, Link Mitra: 14%, Toggle: 7%).
  - Penyesuaian `colspan`: Colspan diperbarui dari 7 menjadi 8 pada state loading, skeleton, dan empty state.
- **Contract & Tests**:
  - `test_admin_outlet_table_8_columns_and_link_mitra_contract` dalam `tests/test_schedule_ui_layout_contract.py`.

## Handling
- Mencegah event bubbling (`event.stopPropagation()`) pada klik tautan Link Mitra agar navigasi ke dashboard mitra tidak memicu pembukaan panel samping Detail Outlet.
- Tautan membuka tab baru (`target="_blank" rel="noopener noreferrer"`) ke URL dinamis mitra (`/mitra/{slug}`).
- Memastikan fallback focus management pada pembukaan drawer tetap aman ke `.outlet-detail-close` / `.outlet-detail-back` setelah CTA mitra di dalam drawer dihapus.
