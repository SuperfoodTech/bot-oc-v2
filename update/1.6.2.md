# v1.6.2

## Whats New

- Konfigurasi `bot-vb` dikembalikan ke `HEADLESS=true`.

## Spesifikasi

- Service Docker `bot-vb` berjalan headless dan tidak membutuhkan X display.
- `.env` global tetap `HEADLESS=true`, sehingga `bot-oc` tidak berubah.
- Perubahan hanya menyentuh mode tampilan browser, bukan alur patrol atau
  aksi outlet.

## Handling

- Jalankan ulang service setelah update konfigurasi:

  ```bash
  docker compose up -d --force-recreate bot-vb
  ```

- Validasi mode melalui log: harus muncul `Launching (headless=True, ...)`.
