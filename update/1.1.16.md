# Update v1.1.16

## Whats New

- ID outlet dipindahkan ke pojok kanan atas card.
- Preview waktu pause menampilkan hari, tanggal, dan jam lengkap.

- ID menggunakan posisi absolut di dalam header card outlet.
- Target pause ditampilkan dalam format `Hari, tanggal bulan tahun pukul HH:MM WIB`.
- Pill waktu buka pada card tetap menggunakan format ringkas `Buka HH:MM WIB`.

## Handling

- Perubahan berlaku untuk pause akhir hari, pause custom, dan preview durasi.
- Nilai timestamp dan timezone backend tidak berubah.
