# v1.6.3

## Whats New

- Konfigurasi mode browser dipusatkan pada satu variabel `HEADLESS` di `.env`.

## Spesifikasi

- `docker-compose.yml` menggunakan `${HEADLESS:-true}` untuk `bot-oc` dan
  `bot-vb`.
- Mengubah `HEADLESS=false` di `.env` akan menerapkan mode GUI ke kedua bot.
- Jika variabel tidak tersedia, nilai default tetap `true`.

## Handling

- Setelah mengubah `.env`, recreate service yang diperlukan:

  ```bash
  docker compose up -d --force-recreate bot-oc bot-vb
  ```

- Validasi nilai aktif melalui log browser: `headless=True` atau `headless=False`.
