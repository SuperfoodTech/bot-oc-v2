# v1.6.3

## Whats New

- Konfigurasi mode browser dipusatkan pada satu variabel `HEADLESS` di `.env`.

## Spesifikasi

- `docker-compose.yml` menggunakan `${HEADLESS:-true}` untuk `bot-oc` dan
  `bot-vb`.
- Deployment server tidak menggunakan mode GUI karena membutuhkan display.
- Jika variabel tidak tersedia, nilai default tetap `true`.

## Handling

- Setelah mengubah konfigurasi headless, recreate service yang diperlukan:

  ```bash
  docker compose up -d --force-recreate bot-oc bot-vb
  ```

- Validasi deployment server melalui log browser: `headless=True`.
