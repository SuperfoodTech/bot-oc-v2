# Dokumentasi Rilis Update v0.3.4

Penambahan service Docker khusus Virtual Brand (VB) untuk deployment server.

**Tanggal Release**: 22 Agustus 2026  
**Jenis Update**: FEATURE/DEPLOYMENT

## What's New

1. Penambahan service `bot-vb` pada `docker-compose.yml`.
2. Bot VB memakai image runtime dan dependency yang sama dengan `fm-bot`; tidak
   ada instalasi dependency kedua.
3. Bot VB berjalan dengan `HEADLESS=true` pada server.
4. Bot VB memakai data terpisah melalui mount:
   - `/app/vb-data/chrome_profile`
   - `/app/vb-data/session.json`
   - `/app/vb-data/credentials.json`
5. Credential VB dipetakan read-only dari host sebagai
   `src/data/credentials allvbadmin.json`.
6. Tidak ada port publik baru dan profile VB tidak dimount ke `fm-bot`.

## Konfigurasi Service

| Komponen | Nilai |
|---|---|
| Nama container | `fm-bot-vb` |
| Service Compose | `bot-vb` |
| Mode browser server | `HEADLESS=true` |
| Chrome subprofile | `shopee_profile` |
| Interval patrol | `30` detik |
| Maksimum retry | `2` kali |
| Database | PostgreSQL service `db` |

## Deployment Server

Pastikan file berikut tersedia di host dan tidak di-commit:

```text
src/data/chrome_profile
src/data/session.json
src/data/credentials allvbadmin.json
```

Jalankan:

```bash
docker compose build bot-vb
docker compose up -d bot-vb
```

Verifikasi:

```bash
docker compose ps bot-vb
docker compose logs --tail=100 -f bot-vb
```

Log awal harus memperlihatkan `headless=True`, brand yang diproses, merchant,
Store ID, action, dan hasil eksekusinya.

## Catatan

Build dan start Docker tidak dijalankan dari workspace development. Deployment
harus dilakukan oleh AI agent/server deployment setelah melakukan pull commit
terbaru.
