# Dokumentasi Rilis Update v0.2.15 -> v0.2.16

Perbaikan pencegahan `script timeout` Selenium dengan `AbortController` 5 detik, retry 3x, dan penambahan fallback deteksi status DOM badge ShopeeFood (`.shopee-food-badge-status-text` / `.shopee-food-badge-status-dot`).

**Tanggal Release**: 18 Agustus 2026  
**Jenis Update**: Patch Stabilitas & Handling Error Bot Patroli

## Whats New

1. **Client-Side Timeout 5 Detik via AbortController**: Setiap panggilan `fetch()` ke API internal Shopee (`/api/seller/store`, `/opening-status/action/open`, `/action/pause`) kini dibungkus dengan JS `AbortController` (max 5.000 ms).
2. **Auto-Retry 2x**: Jika request API menggantung atau melempar error, bot melakukan percobaan ulang (retry) sebanyak 2x secara otomatis sebelum menyerah.
3. **Peningkatan DOM Badge Status Fallback**: Menambahkan pengecekan elemen status badge Shopee Food:
   - **OPEN / BUKA**: Mendeteksi teks `"Buka"` atau `"Open"` pada `.shopee-food-badge-status-text` atau dot style berlatar `rgb(48, 181, 102)`.
   - **CLOSED / TUTUP SEMENTARA / PAUSE**: Mendeteksi teks `"Tutup Sementara"`, `"Pause"`, `"Closed"` pada `.shopee-food-badge-status-text` atau dot style berlatar `rgb(238, 44, 74)`.
4. **Perluasan Script Timeout Selenium**: Menaikkan `driver.set_script_timeout` ke 15 detik untuk memberikan buffer aman melebihi batas timeout client 5 detik.

## Spesifikasi

| Komponen | File | Perubahan |
|---|---|---|
| Bot Status Patrol | `src/shopee/store_status.py` | Penambahan `AbortController` 5s, retry loop 2x, dan DOM badge fallback (Buka/Open vs Tutup Sementara/Pause/Closed) |
| Agency Patrol | `src/agency/browser.py` | Penambahan `AbortController` 5s, retry loop 2x, dan DOM badge fallback (Buka/Open vs Tutup Sementara/Pause/Closed) |
| Driver Core | `src/core/browser.py` | Penyesuaian `set_script_timeout(15)` |

## Handling

1. Karena perubahan ini memodifikasi modul shared/core (`src/shopee/store_status.py`, `src/agency/browser.py`, `src/core/browser.py`), container bot patroli (`fm-bot` / `fm-agency`) perlu di-restart:
   ```bash
   docker compose restart bot agency
   ```
2. Pengujian otomatis dilakukan untuk memastikan tidak ada kesalahan sintaksis Python pada modul yang telah diperbarui.
