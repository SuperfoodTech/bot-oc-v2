# Dokumentasi Rilis Update v0.2.16

Perbaikan penghapusan data admin dan penyempurnaan hasil link dashboard.

**Tanggal Release**: 18 Agustus 2026  
**Jenis Update**: Patch bug dan UX

## Whats New

1. Penghapusan outlet terakhir tidak lagi gagal karena urutan relasi `shopee_accounts` dan `portals`.
2. Tombol salin link diganti menjadi ikon copy kecil tanpa background agar link lebih mudah terlihat di card review.
3. Setelah mitra berhasil disimpan dan link dibuat, tombol kembali tidak lagi menampilkan konfirmasi data akan terhapus.

## Spesifikasi

| Komponen | File | Perubahan |
|---|---|---|
| Delete cleanup | `src/backend/db.py` | Menghapus akun Shopee terkait sebelum portal merchant dihapus |
| Result link | `src/backend/templates/admin_add_merchant.html`, `src/backend/static/css/styles.css` | Tombol salin menggunakan ikon transparan dan state tersalin berbasis tooltip |
| Leave guard | `src/backend/templates/admin_add_merchant.html` | Flow sukses dianggap selesai sehingga tidak memicu dialog discard |

## Handling

1. Pesan error API delete tetap ditampilkan jika backend menolak operasi.
2. Link hasil tetap readonly dan dapat disalin melalui tombol ikon.
3. Deploy perubahan menggunakan:
   ```bash
   docker compose build web
   docker compose up -d --no-deps web
   ```
