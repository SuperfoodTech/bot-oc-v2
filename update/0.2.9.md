# Dokumentasi Rilis Update v0.2.9

Penyeragaman ikon kontrol tampil/sembunyikan passcode.

**Tanggal Release**: 18 Agustus 2026  
**Jenis Update**: Patch UI

## Whats New

1. Kontrol passcode di halaman Tambah Mitra menggunakan ikon eye dan eye-off.
2. Ikon diseragamkan dengan kontrol password pada halaman Login Admin.
3. Accessible label dan state `aria-pressed` tetap diperbarui sesuai kondisi passcode.

## Spesifikasi

| Komponen | File | Perubahan |
|---|---|---|
| Toggle passcode | `src/backend/templates/admin_add_merchant.html` | SVG eye/eye-off dan state visibility |
| Styling icon | `src/backend/static/css/styles.css` | Ukuran dan style stroke konsisten |

## Handling

1. Passcode tetap tersembunyi secara default.
2. Tombol tetap dapat digunakan dengan keyboard dan screen reader.
3. Perubahan hanya memengaruhi kontrol passcode pada halaman Tambah Mitra.
4. Deploy perubahan frontend/backend menggunakan:
   ```bash
   docker compose build web
   docker compose up -d --no-deps web
   ```
