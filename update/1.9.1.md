# v1.9.1

## Whats New

- Menambahkan pengecualian seluruh `src/data/**` pada Docker build context.

## Spesifikasi

- Credential, session, dan Chrome profile tidak disalin ke image.
- Service `bot-vb` tetap menerima data tersebut melalui volume Docker yang
  sudah dikonfigurasi.

## Handling

- Mencegah BuildKit membaca file cache Chrome lokal yang permission-nya tidak
  dapat diakses saat proses build.
- Tidak mengubah worker, browser runtime, database, atau service bot-OC.
