# Release Note 1.13.0

## Whats New
- Mengoptimalkan tampilan drawer detail outlet (`outletDetailPanel`) pada Dashboard Admin dengan membuang data operasional/kontrak yang redundan dan memfokuskan antarmuka pada jadwal operasional serta riwayat aktivitas langsung.
- Menghapus 11 item data/status dari drawer:
  1. Baris `Status live Shopee` (`Shopee: Buka` / `Tutup`).
  2. Keterangan bantuan status: `Nilai terakhir yang diterima dari XHR Shopee.`
  3. Kontrak bot beserta fase dan live state.
  4. Status pause manual (`Pause sampai`).
  5. Timestamp pembacaan status (`Sinkron terakhir`).
  6. Ringkasan toggle terakhir.
  7. Timestamp waktu toggle audit log.
  8. Catatan toggle (`last_toggle_reason`).
  9. Status subscription layanan mitra.
  10. Password dashboard mitra.
  11. Catatan jam khusus.
- Menghilangkan dropdown/akordion dan tombol minimize pada jadwal Shopee: panel **Jadwal reguler Shopee** kini langsung tampil terbuka secara statis dan rapi di bawah kartu identitas outlet (`.outlet-detail-identity`) tanpa tombol expand/collapse atau chevron.
- Menambahkan kartu **Aktivitas terbaru** di bawah jadwal Shopee yang menampilkan riwayat log audit outlet (maksimal 10 log) dengan format dan styling identik dengan yang ada di Dashboard Mitra (`user_dashboard.html`), mencakup:
  - Role pill (`Bot`, `Admin`, `Merchant`, `Info`).
  - Timestamp waktu aksi (format WIB ringkas).
  - Judul aktivitas dan subjudul toko/outlet.
  - State kosong (`Belum ada aktivitas.`) dan penanganan error respons.
- Menerapkan pembatasan scrollbar internal: seluruh drawer panel (`.outlet-detail-panel` dan `#outletDetailContent`) menggunakan `overflow: hidden`, sehingga scrollbar hanya aktif dan muncul secara eksklusif pada container daftar log (`.outlet-detail-history-list`).
- Menghapus label catatan keamanan pada Dashboard Mitra (`user_dashboard.html`): kartu catatan `"Kata sandi akun Anda dikelola oleh admin FoodMaster dan tidak dapat diubah oleh mitra."` (`#accountNotice`) ditiadakan agar antarmuka mitra lebih bersih dan fokus.

- **Target File**:
  - `src/backend/templates/user_dashboard.html`:

    - Penambahan test `test_admin_outlet_detail_drawer_streamlined_layout_and_internal_log_scroll_contract`.

## Handling
- Mencegah *race conditions* saat pergantian outlet yang dipilih: respon fetch log hanya dirender jika `outletDetailActiveStoreId` masih sesuai dengan `storeId` yang diminta.
- Menjaga konsistensi kontras warna dan tipografi badge peran (`is-bot`, `is-admin`, `is-merchant`, `is-neutral`).
- Memastikan tidak ada scrollbar ganda (*double scrollbar*) pada viewport desktop, tablet, maupun layar sentuh mobile.
