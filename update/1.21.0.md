# Release Update 1.21.0 - Standalone WhatsApp Gateway Web UI & Admin Dashboard Integration

## Whats New

Integrasi penuh microservice **WhatsApp Gateway Console (`bot-wa`)** yang beroperasi secara independen di server Raspberry Pi (`168.144.143.203:3002`) sebagai service systemd (`bot-wa.service`). Halaman UI konsol ini diintegrasikan secara langsung ke dalam tab **Bot WA** pada Dashboard Admin FoodMaster tanpa memerlukan tombol interupsi CTA tambahan.

---

## Spesifikasi

1. **Standalone Web UI Console (`bot-wa/public/index.html`)**:
   - Didesain secara independen dan bersih menggunakan tipografi *Plus Jakarta Sans*, color palette modern, serta tanpa dependensi eksternal yang tidak perlu.
   - Menampilkan status koneksi real-time, antrean pesan, jam update terakhir, serta QR Code (generated server-side Base64 PNG).
   - Menampilkan detail akun WhatsApp yang sedang terhubung: **Nama Akun** dan **Nomor Telepon** (format bersih e.g. `089523445543`).

2. **Perbaikan Transisi Status QR Scan & UX Handshake**:
   - Menghilangkan flash pesan error `DISCONNECTED` sementara saat perpindahan dari scan QR menuju sesi terhubung.
   - Menampilkan kartu transisi halus **"Menghubungkan Sesi WA..."** (`badge-connecting`) selama proses verifikasi enkripsi handshake Baileys.

3. **Tombol Interaktif Refresh Status**:
   - Fungsi `manualRefreshStatus` ditempatkan di dalam tag `<script>` dengan proteksi durasi minimal 400ms.
   - Menyediakan visual feedback langsung saat diklik: ikon spinner berputar, teks tombol berubah menjadi `"Memeriksa..."`, dan jam update terakhir memberikan efek *pulse highlight* warna hijau begitu data diperbarui.

4. **Integrasi Admin Dashboard (`src/backend/templates/admin_tab_wa.html` & `admin_dashboard.html`)**:
   - Tab navigasi sidebar **Bot WA** mengarahkan langsung ke konsol gateway via iframe 100% height.
   - Menyediakan fallback controller REST API di backend FastAPI (`/api/v1/admin/wa/status`, `/api/v1/admin/wa/logout`, `/api/v1/admin/wa/test`).

---

## Handling

- **Zero-Downtime Deployment**:
  - Update Web Backend di-deploy menggunakan `docker compose build web && docker compose up -d --no-deps web` tanpa mengganggu container patroli `fm-bot`.
- **Systemd Microservice pada Raspberry Pi**:
  - Microservice `bot-wa` dikelola melalui systemd unit `/etc/systemd/system/bot-wa.service` pada server Pi (`168.144.143.203`).
