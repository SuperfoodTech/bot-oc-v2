# Dokumentasi Rilis Update v0.2.15

Penataan ulang result sukses pada halaman Tambah Mitra.

**Tanggal Release**: 18 Agustus 2026  
**Jenis Update**: Patch UX

## Whats New

1. Result sukses tidak lagi tampil di bawah seluruh kolom form.
2. Result dipindahkan ke card Review, tepat di bawah tombol `Simpan & generate link`.
3. Link dashboard dan tombol `Salin` berada dalam satu area result yang sama.

## Spesifikasi

| Komponen | File | Perubahan |
|---|---|---|
| Success result | `src/backend/templates/admin_add_merchant.html` | Dipindahkan ke dalam card Review |
| Copy link | `src/backend/templates/admin_add_merchant.html` | Tetap tersedia tepat di samping link hasil |

## Handling

1. Result tetap tersembunyi sampai endpoint pembuatan mitra berhasil.
2. Setelah berhasil, halaman melakukan scroll ke result pada card Review.
3. Payload dan endpoint backend tidak berubah.
4. Deploy perubahan frontend/backend menggunakan:
   ```bash
   docker compose build web
   docker compose up -d --no-deps web
   ```
