# Update 1.16.1

## Whats New
- Penyelarasan penuh dan konsistensi komponen toolbar filter Virtual Brand (VB):
  - Field filter **Store ID** pada halaman VB dikonversi menjadi custom searchable dropdown (`.filter-select`) identik dengan field filter `Nama Grup`, `Status Master`, `Status Grup`, `Portal`, dan `Store ID` pada tab Agency.
  - Memperbaiki aturan CSS warisan (`42px`) pada `.admin-shell .admin-main .reset-filter-button` dan `.form-input` menjadi seragam `36px` pada mode desktop.
  - Tombol **Reset Filter** pada kartu filter VB diselaraskan tingginya tepat `36px` dengan icon `14px` dan class `btn-compact`.
  - Teks placeholder pencarian di dalam dropdown Store ID menggunakan `"Cari Store ID..."` dan tombol reset menggunakan label `"Reset filter"`.

## Spesifikasi
- **Frontend Templates & JS**:
  - `src/backend/templates/admin_tab_vb.html`:
    - `#vbStoreIdFilter` diubah dari `<input type="search">` menjadi `<select id="vbStoreIdFilter" class="form-input filter-select" aria-label="Filter Store ID" onchange="filterVBTable()"><option value="">Semua Store ID</option></select>`.
    - Tombol reset VB menggunakan class `btn-outline btn-compact reset-filter-button vb-reset-button` dan teks `"Reset filter"`.
  - `src/backend/templates/admin_dashboard.html`:
    - `syncVbFilterOptions(brandViews)`: Mengambil daftar unik `storeId` dari seluruh brand/outlet, menyusunnya secara numerik/alfabetis, dan mengisinya ke `#vbStoreIdFilter` serta `#mobileVbStoreIdFilter`, lalu memanggil `setupCustomFilterDropdowns()`.
    - `setupCustomFilterDropdowns()`: Mendaftarkan `'vbStoreIdFilter'` ke `SEARCHABLE_IDS` dan `PLACEHOLDERS` (`'Cari Store ID...'`).
- **CSS Styles**:
  - `src/backend/static/css/styles.css`:
    - Mengubah deklarasi legacy `.admin-shell .admin-main .filter-field .form-input` dan `.admin-shell .admin-main .reset-filter-button` dari `42px` menjadi `36px`.
    - Mengubah ukuran icon SVG reset filter dari `18px` menjadi `14px`.
- **Tests**:
  - `tests/test_schedule_ui_layout_contract.py`: Memverifikasi kehadiran `#vbStoreIdFilter` dan tombol reset filter pada layout contract.

## Handling
- Penyelarasan tinggi elemen (`36px`) dan `box-sizing: border-box` mencegah pergeseran vertikal (*vertical misalignment*) antara field input Store ID, custom select trigger, dan tombol reset filter pada grid filter VB.
- Deployment menggunakan zero-downtime deployment command (`docker compose build web && docker compose up -d --no-deps web`) tanpa menginterupsi bot patroli maupun database.
