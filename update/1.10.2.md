# v1.10.2

## Whats New

- Sinkronisasi otomatis status pause kedaluwarsa di awal siklus patroli worker bot.
- Validasi parameter `pause_until` agar tidak mengirim timestamp masa lalu ke API Shopee.
- Koreksi struktur file kredensial dan username akun patroli Virtual Brand (VB) ke `allvbadmin`.
- Proteksi dan pembersihan data kolom `Status` pada spreadsheet VB agar tidak dianggap sebagai portal/store ID dummy.

## Spesifikasi

- `main-bot/src/worker.py` dan `main-vb/src/worker.py` memanggil `db.sync_expired_user_pauses()` sebelum memproses evaluasi outlet.
- `_pause_end_time_ms()` mengembalikan `None` apabila waktu `pause_until` sudah lewat dari waktu saat ini (`Asia/Jakarta`), sehingga menggunakan durasi pause default dan tidak memicu error API Shopee.
- `main-vb/src/db.py` mengikat outlet Virtual Brand ke `USERNAME` (`allvbadmin`) dan `PASSWORD` (`Master!00!`) dari `config.py`.
- `main-vb/src/db.py` menambahkan fungsi `sync_expired_user_pauses()` untuk mengembalikan status brand VB yang telah habis masa timed pause-nya ke `ON`.
- `main-vb/src/db.py`, `main-vb/src/importer.py`, dan `src/backend/vb.py` memfilter kolom header `Status`/`Status Import` dan memastikan hanya Store ID numerik yang diproses.
- Membersihkan record dummy lama (`Store ID: Aktif/Nonaktif`, `Portal: Status`) dari PostgreSQL.
- `src/data/credentials allvbadmin.json` diperbaiki dengan key `"allvbadmin"`.
- `docker-compose.yml` menambahkan konfigurasi `ALLOWED_USERNAMES=allvbadmin` dan `VB_SHOPEE_USERNAME=allvbadmin` pada service `bot-vb`.

## Handling

- Mencegah kegagalan aksi `ACTION_CLOSE` pada outlet yang memiliki riwayat pause kedaluwarsa.
- Menghilangkan loop kegagalan login bot VB akibat salah kirim username `auto7313` dengan password `Master!00!`.
- Menghilangkan error `MERCHANT_NOT_FOUND: Status` dan `Store not found, storeID:0` pada patroli Virtual Brand.
- Menjaga aturan byte-for-byte identity antara `main-bot/src/worker.py` dan `main-vb/src/worker.py`.
