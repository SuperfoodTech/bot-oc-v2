# v1.10.9

## Whats New

- Menghapus duplikasi teks informasi waktu buka kembali (`Buka kembali otomatis pada ...`) di bawah label toggle "Buka otomatis" pada Dashboard Mitra (`user_dashboard.html`). Keterangan waktu buka kembali kini ditampilkan secara tunggal dan dinamis pada baris meta berikon jam (`Akan buka kembali pada ... · Tersisa ... menit`).
- Menambahkan tombol **Salin Store ID** (`btn-copy-icon`) pada nilai Store ID di tabel desktop, kartu mobile, dan panel drawer `Detail Outlet` admin dengan background transparan yang selaras dengan teks.
- Menambahkan toast notifikasi berlatar belakang hitam (`toast-dark` / background `#18181b` dengan teks putih `#ffffff` dan icon centang putih) ketika Store ID berhasil disalin ke clipboard.
- Menata ulang posisi tombol tautan **Buka Dashboard Mitra** pada panel drawer `Detail Outlet` admin menjadi tombol aksi *full-width* tepat di bawah kartu identitas outlet (di bawah nama outlet, store ID, dan badge merchant, sebelum ringkasan status operasional).
- Menghapus badge/tulisan status ganda di bagian paling atas panel detail outlet (`Sedang buka` dan subteks `Outlet mengikuti jam operasional Shopee`) agar header panel langsung menampilkan identitas outlet.
- Menghapus tombol **Hapus outlet** dari footer drawer detail outlet admin untuk menjaga kebersihan tampilan dan keamanan data.

## Spesifikasi

- Pada normalisasi status runtime (`src/backend/db.py` dan `main-vb/src/backend/db.py`):
  - `display_note` untuk fase `PAUSE` distandardisasi menjadi `"Outlet sedang ditutup sementara."`, menghilangkan penulisan duplikat string timestamp statis.
  - Pada `user_dashboard.html`, subteks toggle `getOutletAutomationDetail` menampilkan keterangan umum status tutup sementara, sedangkan rincian sisa waktu dan jam buka spesifik dikelola secara dinamis oleh `getOutletPauseLine`.
- Pada tabel admin (`renderAdminTable` di `admin_dashboard.html`):
  - Kolom Store ID pada tabel desktop dibungkus dalam `.store-id-cell` yang memuat kode Store ID dan button salin `.btn-copy-icon`.
  - Chip Store ID pada kartu mobile (`.admin-mobile-store-chip`) memuat button salin `.btn-copy-icon.is-chip`.
- Pada drawer `Detail Outlet` di dashboard admin:
  - Baris Store ID (`.outlet-detail-store-id`) memuat tombol salin `.btn-copy-icon`.
  - Mengklik tombol salin memanggil `copyStoreId(event, storeId)` yang mencegah *event bubbling* (`stopPropagation`), menyalin teks Store ID ke clipboard, dan memicu `showToast('Store ID <id> berhasil disalin!', 'dark')`.
  - Tombol `.outlet-detail-mitra-full-btn` diletakkan tepat di bawah blok identitas (`.outlet-detail-mitra-action`), membentang penuh (*full-width*) dengan label `Buka Dashboard Mitra` dan icon tautan eksternal yang membuka `/mitra/<slug>` di tab baru.
- Pada komponen Toast:
  - Kelas `.toast-custom.toast-dark` ditambahkan ke `styles.css` dengan background `#18181b`, font `#ffffff`, border `#18181b`, dan bayangan halus `rgba(0, 0, 0, 0.35)`.

## Handling

- Fungsi `copyStoreId` mendukung `navigator.clipboard` dengan fallback aman ke temporary input element untuk kompatibilitas multi-browser.
- Event click pada tombol copy Store ID di tabel maupun mobile card tidak memicu pembukaan atau perubahan state drawer detail outlet.
- Modal konfirmasi hapus data (`deleteModal`) tetap ada di level template admin untuk kegunaan sistem internal, tetapi tombol pemicunya di drawer outlet telah ditiadakan.
