# Dokumentasi Rilis Update v1.1.0

Penambahan indikator pause pada card outlet mitra.

**Tanggal Release**: 24 Agustus 2026  
**Jenis Update**: MINOR / UX

## Whats New

1. Card outlet mitra menampilkan pill kuning berisi waktu buka exact, misalnya
   `Buka pkl 12:19 WIB`, ketika outlet sedang pause terjadwal.
2. Card juga menampilkan pill hijau berisi sisa waktu, misalnya
   `Tersisa 30 menit`.
3. Kedua pill menggunakan bentuk rounded 50% dan foreground putih.
4. Pill tidak ditampilkan untuk outlet yang OFF tanpa jadwal pause.

## Spesifikasi

| Komponen | File | Perubahan |
|---|---|---|
| Outlet card | `src/backend/templates/user_dashboard.html` | Menampilkan label pause |
| Styling | `src/backend/static/css/styles.css` | Pill kuning dengan teks putih |
