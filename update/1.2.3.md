# Update v1.2.3

## Whats New

- Halaman login admin sekarang menggunakan font Nunito.

## Spesifikasi

- Font dimuat dari Google Fonts dengan weight 400 sampai 800.
- Penerapan dibatasi pada `.admin-login-page` dan seluruh elemen di dalamnya.
- Asset stylesheet login memakai cache-busting baru.

## Handling

- Dashboard mitra dan halaman admin lain tetap menggunakan font sebelumnya.
- Jika Google Fonts tidak tersedia, browser menggunakan fallback system sans-serif.
