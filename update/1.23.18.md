# Release Notes v1.23.18: Deterministic Python Runtime Memory Reclamation & Proactive Browser Recycling

## Ringkasan Pembaruan
Pembaruan ini menuntaskan masalah akumulasi memori pada operasional bot patroli 24/7 (`main-bot` dan `main-vb`) melalui dua pilar utama:
1. **Deterministic Python Runtime Memory Reclamation**: Mengintegrasikan pemanggilan C `libc.so.6` `malloc_trim(0)` di setiap akhir siklus loop daemon (blok `finally:`), memastikan unmapped memory pages dan fragmentasi memory arena Python langsung dikembalikan ke Kernel OS.
2. **Proactive Browser Instance Recycling & Anti-BFCache Protection**: Mengotomatisasi siklus refresh browser Chromium setiap 100 siklus patroli hanya pada *safe idle window* (tidak ada antrean demand/aksi dan tidak ada boundary kritis dalam $< 60$ detik) dengan *instant re-warmup* (Zero Cold-Start, Zero OTP) serta mematikan BackForwardCache.

## Detail Perubahan

### 1. `src/core/browser.py`
- Menambahkan flag `--disable-features=BackForwardCache,Translate,OptimizationHints,MediaRouter` untuk mencegah Chromium menyimpan snapshot riwayat navigasi DOM halaman Shopee di RAM.

### 2. `main-bot/src/worker.py` & `main-vb/src/worker.py`
- Menambahkan fungsi `recycle_browser_sessions()` yang diproteksi `SYNC_LOCK` untuk menutup sesi browser lama via `cleanup_driver_process()`, membersihkan alokasi memori glibc, dan langsung melakukan re-warmup browser baru yang bersih (~80 MB) menggunakan profile disk yang ada.
- Menjaga 100% byte-for-byte parity antara worker Agency dan Virtual Brand.

### 3. `main-bot/src/daemon.py` & `main-vb/src/daemon.py`
- Menambahkan pemicu recycle otomatis setiap `BROWSER_RECYCLE_INTERVAL_CYCLES` (default 100 siklus).
- Menerapkan mekanisme penundaan (*deferral*) jika terdeteksi ada aksi yang sedang berjalan (`actions_taken > 0`), jeda tidur singkat mendekati jadwal toko (`next_sleep_seconds < IDLE_REEVALUATION_SECONDS`), atau ada antrean retry pending (`FAILED_RETRY_TRACKER`).
- Menambahkan `malloc_trim(0)` di blok `finally:`.
