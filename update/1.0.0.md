# Dokumentasi Rilis Update v1.0.0

Perbaikan durasi pause Shopee, timezone, dan keterbacaan informasi status.

**Tanggal Release**: 24 Agustus 2026  
**Jenis Update**: MAJOR BASELINE

## Whats New

1. Durasi pause dari dashboard mitra sekarang diteruskan sampai ke worker.
2. `pause_until` dikonversi ke `pause_end_time` dalam Unix timestamp milidetik
   sesuai payload API Shopee.
3. Pilihan 30 menit tidak lagi menggunakan fallback 1 hari (`1440` menit).
4. Shopee tetap menjadi pihak yang menjadwalkan pembukaan otomatis outlet.
5. Status pause menampilkan sisa waktu dan waktu target outlet kembali ON.
6. Seluruh waktu tampilan dan log menggunakan timezone WIB/GMT+7.
7. Pecahan detik dan microseconds dihilangkan dari timestamp log dan status.
8. Font status, countdown, riwayat, dan catatan tabel diperbesar serta dibuat
   lebih tebal dengan warna kontras tinggi.
9. Response endpoint pause mengembalikan `pause_start_time`, `pause_end_time`,
   dan timezone untuk verifikasi tanpa menjalankan bot.
10. Nilai `pause_until` disimpan sebagai waktu timezone-aware agar PostgreSQL
   tidak menggeser waktu WIB menjadi UTC.
11. Endpoint pause mengembalikan window waktu yang dapat diverifikasi tanpa
   menyalakan worker bot.
12. Refresh data setelah pause/resume mempertahankan session mitra dan tidak
   lagi mengosongkan halaman kembali ke login.
