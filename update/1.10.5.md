# v1.10.5

## Whats New

- Memperbaiki scrolling di tab Logs admin agar tidak memicu scroll halaman global (window/body level).
- Seluruh konten Logs kini terisolasi dalam container internal (`.logs-page-shell`) dengan scrollbar tersendiri pada tampilan desktop, konsisten dengan tab Virtual Brand.
- Header admin dan sidebar navigasi tetap terkunci di posisinya saat meninjau daftar log aktivitas dan error bot.

## Spesifikasi

- `src/backend/templates/admin_tab_bot.html` membungkus konten `#paneLogs` ke dalam container `.logs-page-shell`.
- `src/backend/static/css/styles.css` menambahkan aturan layout `#paneLogs.active` (`height: 100%; min-height: 0;`) dan `.logs-page-shell` (`height: 100%; overflow-y: auto; overscroll-behavior: contain; padding-bottom: 24px;`) pada media query desktop (>= 701px) serta fallback responsif pada mobile.
- `src/backend/templates/admin_dashboard.html` menambahkan reset `scrollTop = 0` untuk `.logs-page-shell` saat berpindah ke tab Logs.

## Handling

- Mencegah browser window scroll secara global ketika daftar log atau error bertambah panjang.
- Menjaga konsistensi pengalaman navigasi admin antar-tab (Agency, Virtual Brand, Logs, Settings) tanpa merusak tampilan mobile.
