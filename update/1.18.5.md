# Release Update 1.18.5 - Optimalisasi Frekuensi Polling Web Dashboard & Efisiensi Resource PostgreSQL

## Whats New

Penerapan optimasi frekuensi polling web dashboard (Admin Dashboard, Dashboard Mitra, dan Bot Monitoring) dari 15 detik menjadi 60 detik berbasis arsitektur *Event-Driven Hybrid (SSE Push + Fallback)*. Pembaruan ini menghemat hingga 75% traffic request HTTP dan query database PostgreSQL tanpa mengurangi responsivitas real-time antarmuka pengguna.

---

## Spesifikasi

1. **Relaksasi Interval Polling Cadangan (`src/backend/templates/`)**:
   - `admin_dashboard.html`: `ADMIN_OUTLET_SYNC_REFRESH_MS` disesuaikan dari `15000` (15s) menjadi `60000` (60s). `fetchBotStatus` disesuaikan dari `15000` menjadi `60000`.
   - `user_dashboard.html`: `USER_OUTLET_SYNC_REFRESH_MS` disesuaikan dari `15000` (15s) menjadi `60000` (60s).
   - `admin_bot.html`: `fetchBotStatus` dan `fetchBotActivity` disesuaikan menjadi `60000` (60s).

2. **Instant Sync pada Event `visibilitychange`**:
   - Menambahkan event listener `visibilitychange` pada dashboard Admin dan Mitra. Saat user membuka kembali (*focus*) tab browser yang sebelumnya di-minimize atau berada di background, browser langsung memicu sinkronisasi data seketika (*instant catch-up*) tanpa harus menunggu interval 60 detik.

3. **Preservasi Real-Time UX**:
   - Server-Sent Events (SSE) `/api/v1/admin/events` tetap aktif mendorong perubahan status secara instan (< 200ms) saat bot atau admin melakukan aksi buka/tutup toko.
   - Timer hitung mundur durasi pause mitra (`getPauseEndDate`) tetap berjalan mulus per-detik di browser lokal.

---

## Handling

- **Zero-Downtime Deployment**:
  - Diterapkan menggunakan perintah standar non-bot:
    ```bash
    docker compose build web && docker compose up -d --no-deps web
    ```
- **Zero-Interruption Bot 24/7**:
  - Service daemon patroli `bot-oc.service` (PID 882897) dan `bot-vb.service` (PID 883089) tetap aktif berjalan 24/7 tanpa mengalami restart PID ataupun gangguan sesi browser.
