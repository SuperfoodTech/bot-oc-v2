# Dokumentasi Rilis Update v0.2.14

Perbaikan navigasi mobile dan alignment numbering section halaman Tambah Mitra.

**Tanggal Release**: 18 Agustus 2026  
**Jenis Update**: Patch UX

## Whats New

1. Flow arrow back mobile diverifikasi menuju `/admin/dashboard?tab=outlets` dengan benar.
2. Flow form terisi menampilkan modal konfirmasi sebelum data dihapus ketika meninggalkan halaman.
3. Numbering section `01`, `02`, dan `03` dibuat memiliki ukuran, posisi, dan alignment yang sama.

## Spesifikasi

| Komponen | File | Perubahan |
|---|---|---|
| Navigasi mobile | `src/backend/templates/admin_add_merchant.html` | Back link dan leave confirmation diverifikasi |
| Section numbering | `src/backend/static/css/styles.css` | Badge 30x30px dengan alignment terpusat |

## Handling

1. Form kosong dapat kembali langsung ke operasional outlet.
2. Form yang sudah diisi meminta konfirmasi; `Lanjutkan` menuju operasional dan `Batal` mempertahankan form.
3. Perubahan numbering hanya memengaruhi visual section pada halaman Tambah Mitra.
4. Deploy perubahan frontend/backend menggunakan:
   ```bash
   docker compose build web
   docker compose up -d --no-deps web
   ```
