# Release Notes v1.23.19: Native WhatsApp Gateway Integration, Anti-Spam Deduplication & Custom Modals

## Ringkasan Pembaruan
Pembaruan ini merombak antarmuka WhatsApp Gateway Console menjadi komponen **100% Native SPA Dashboard** di port yang sama (`3001`), mengeliminasi wrapping `<iframe>`, menyelaraskan desain notifikasi 1:1 dengan format resmi Agency Discord, serta memperkuat engine pengiriman WhatsApp dengan proteksi **Anti-Spam, Deduplikasi 2 Arah, Humanized Pacing, dan Custom Confirmation Modal**.

## Detail Perubahan

### 1. `src/backend/templates/admin_tab_wa.html` & `src/backend/templates/admin_dashboard.html`
- **Zero-Iframe Native Embedding**: Mengubah tab Bot WA dari pemuatan iframe menjadi komponen DOM native di dalam `#paneWA` dashboard admin pada port `3001`.
- **Custom Confirmation Modal**: Menggantikan dialog native browser (`confirm()`) pada fitur *Putuskan Sesi WhatsApp* dengan modal konfirmasi custom FoodMaster yang bersih dan minimalis tanpa teks berlebih.
- **Visual Harmonization**:
  - Tombol **"Fetch dari Sheet"** diselaraskan 1:1 dengan warna merah tema Agency (`#be1a1a`), ikon dokumen SVG, dan hover state.
  - Kolom **Owner** disederhanakan tanpa badge durasi/paket, avatar icon, atau teks sub-label.
  - Tombol jumlah outlet disajikan dalam 1 baris (`white-space: nowrap`) tanpa chevron arrow.
- **Routing Proxy Robustness**: Menyempurnakan pemetaan endpoint URL (`/api/v1/admin/wa/*`) untuk status gateway, fetch data sheet, rincian owner, dan pemutusan sesi.

### 2. `bot-wa/src/index.js` & `bot-wa/public/index.html`
- **Anti-Spam & Deduplication Engine**: Mengintegrasikan `dedupCache` (TTL 5 menit) berbasis `dedupKey` (`BOT:{phone}:{event_type}:{store_id}`) yang secara otomatis memblokir pesan burst/duplikat.
- **Anti-Ban Humanization (Typing Simulation & Jitter Pacing)**:
  - Mengirimkan event simulasi mengetik (`composing`) selama 800ms–1600ms sebelum pesan aktual dikirimkan.
  - Mengatur jeda acak (*jitter delay*) 2.5s–4.5s antar pengiriman pesan untuk menghindari deteksi spam oleh algoritma WhatsApp.
  - Membatasi antrean maksimal (100 pesan) dan mencegah duplikasi task identik di antrean.
- **1:1 Agency Notification Format Alignment**: Menyelaraskan teks notifikasi WhatsApp buka/tutup outlet dengan template resmi Discord Agency (Nama Outlet, Store ID, tautan ShopeeFood, dan footer resmi WA CS FoodMaster).

### 3. `src/core/notifier.py`
- Menambahkan pemeriksaan tanda tangan deduplikasi atomik (`sig_raw = f"WA:{event_type}:{store_id}:{phone}"`) pada `send_wa_webhook_async` dengan TTL cache 5 menit untuk mencegah penembakan webhook ganda dari Python patrol engine.

### 4. `systemd/setup.sh` & `systemd/bot-wa.service`
- Menambahkan template dan installer otomatis systemd service `bot-wa` untuk deployment mandiri di level OS Linux.
