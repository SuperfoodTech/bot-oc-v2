# Dokumentasi Rilis Update v0.2.26

Menambahkan logo FoodMaster pada header dashboard admin dan mitra.

**Tanggal Release**: 19 Agustus 2026  
**Jenis Update**: Minor visual update

## Whats New

1. Header dashboard mitra sekarang menggunakan logo FoodMaster.
2. Header dashboard admin sekarang menggunakan logo FoodMaster.
3. Teks brand `FoodMaster` pada header dihapus agar tidak tampil ganda.
4. Subtitle `Operasional & Log Bot` dihapus dari header admin.
5. Cache stylesheet diperbarui agar logo langsung tampil setelah deploy.

## Spesifikasi

| Komponen | File | Perubahan |
|---|---|---|
| Logo asset | `src/backend/static/Logo_FoodMaster.png` | Menambahkan asset logo dari repository |
| Admin header | `src/backend/templates/admin_dashboard.html`, `src/backend/templates/admin_header.html` | Mengganti teks brand dengan logo dan menghapus subtitle |
| Mitra header | `src/backend/templates/user_dashboard.html` | Mengganti teks FoodMaster dengan logo |
| Logo sizing | `src/backend/static/css/styles.css` | Menambahkan ukuran responsif untuk header admin dan mitra |

## Handling

1. Logo menggunakan asset yang sama di seluruh dashboard.
2. Header admin hanya menampilkan logo tanpa subtitle tambahan.
3. Deploy perubahan menggunakan:
   ```bash
   docker compose build web
   docker compose up -d --no-deps web
   ```
