# Dokumentasi Rilis Update v0.2.12

Penambahan informasi akun mitra pada card review halaman Tambah Mitra.

**Tanggal Release**: 18 Agustus 2026  
**Jenis Update**: Patch UX

## Whats New

1. Card review sekarang menampilkan Email Google mitra.
2. Card review sekarang menampilkan Passcode secara langsung karena halaman ini hanya dapat diakses admin.
3. Nilai review diperbarui secara realtime ketika field berubah.

## Spesifikasi

| Komponen | File | Perubahan |
|---|---|---|
| Review summary | `src/backend/templates/admin_add_merchant.html` | Field Email Google dan Passcode ditambahkan |
| Passcode admin | `src/backend/templates/admin_add_merchant.html` | Passcode ditampilkan plain text untuk kebutuhan operasional admin |

## Handling

1. Email yang belum diisi ditampilkan sebagai `Belum diisi`.
2. Passcode tetap berada di halaman internal admin dan ditampilkan plain text.
3. Perubahan tidak memengaruhi payload submit ke backend.
4. Deploy perubahan frontend/backend menggunakan:
   ```bash
   docker compose build web
   docker compose up -d --no-deps web
   ```
