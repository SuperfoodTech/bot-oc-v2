# Dokumentasi Rilis Update v0.2.7

Penyederhanaan kontrol kembali pada halaman Tambah Mitra.

**Tanggal Release**: 18 Agustus 2026  
**Jenis Update**: Patch UX

## Whats New

1. Tombol kembali diubah menjadi ikon panah kiri solid saja.
2. Teks, border, dan background tombol dihapus agar kontrol lebih ringan secara visual.
3. Area klik tetap berukuran minimum 44px dan dilengkapi `aria-label` serta `title`.

## Spesifikasi

| Komponen | File | Perubahan |
|---|---|---|
| Kontrol kembali | `src/backend/templates/admin_add_merchant.html` | SVG panah kiri solid tanpa teks |
| Styling kontrol | `src/backend/static/css/styles.css` | Transparent button dengan hit area 44px |

## Handling

1. Ikon tetap mengarah ke `/admin/dashboard?tab=outlets`.
2. Tooltip browser dan accessible name tetap menjelaskan tujuan tombol.
3. Perubahan hanya memengaruhi halaman Tambah Mitra.
4. Deploy perubahan frontend/backend menggunakan:
   ```bash
   docker compose build web
   docker compose up -d --no-deps web
   ```
