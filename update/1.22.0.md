# Release Update 1.22.0 - Virtual Brand Hero Card UI Integration & Layout Parity

## Whats New

Penyempurnaan tampilan **Dashboard Virtual Brand Publik (`/brand/{slug}`)**:
1. **Perbaikan Bug Display Loading, Error Panel, dan Bottom Sheet (`[hidden]`)**:
   - Menambahkan aturan CSS `.brand-loading-panel[hidden], .brand-error-panel[hidden], .brand-dashboard-content[hidden], .brand-outlets-collapse[hidden], .brand-bottom-sheet-backdrop[hidden], .brand-bottom-sheet[hidden], .modal-overlay[hidden] { display: none !important; }` pada `styles.css`.
   - Menghilangkan bug di mana panel loading (*"Memuat data brand..."*) dan error panel (*"Brand tidak ditemukan"*) tetap tampil di bagian atas halaman saat data brand sudah berhasil dimuat.
   - Menghilangkan bug di mana Bottom Sheet Jadwal Operasional tidak dapat ditutup (tetap tertampil saat `closeScheduleBottomSheet()` dipanggil).

2. **Integrasi Tombol Tanpa Background ("Tanpa BG"), Eliminasi Badge "Virtual Brand", & Eliminasi Toggle Night Mode**:
   - Menghapus badge teks `"Virtual Brand"` dari bagian atas Hero Card (`.brand-hero-card`).
   - Menghapus tombol toggle tema malam/terang (`.theme-toggle`) dari header halaman publik brand.
   - Mengubah style tombol `"Lihat Jadwal"` dan `"Daftar Outlet (N)"` menjadi transparan (`background: transparent !important;`) tanpa latar belakang abu-abu (*clean outline action buttons*).
   - Menghapus garis pembatas bawah (`border-bottom: none !important;`) di bawah header agar tampilan menyatu secara halus dengan kartu dashboard.

3. **Label Status Tanpa Background Fill ("Tanpa BG") & Perbaikan Responsif Mobile**:
   - Mengubah tampilan label status outlet (`.brand-status-pill`) menjadi teks berwarna tanpa background pill/box (`background: transparent !important; padding: 0;`).
   - Memperbaiki penyempitan baris tabel outlet pada layar mobile (`flex: 1 1 50%` pada `.brand-outlet-col-main` dan `flex: 0 1 50%` pada `.brand-outlet-col-status`).
   - Menghilangkan pemotongan huruf vertikal per-karakter (`word-break: normal; overflow-wrap: break-word;` pada `.brand-outlet-name`) sehingga nama outlet dan teks status tampil rapi, proporsional, dan bersih pada seluruh ukuran layar smartphone.

4. **Parity 1:1 Perilaku Switch Toggle Brand (Identik dengan Dashboard Mitra)**:
   - Menghilangkan class `.admin-table-toggle` pada toggle brand agar menggunakan class dasar `.switch-toggle` yang identik 1:1 dengan Dashboard Mitra (`user_dashboard.html`).
   - State di luar jadwal operasional (`state-closed`): toggle di posisi kiri (`translateX(0)`), warna abu-abu (`#cbd5e1`), berstatus `disabled`, dan menampilkan warning toast edukatif jika diklik (`handleBrandToggleAttempt`).
   - State tutup/pause sementara (`state-paused`): toggle di posisi kiri (`translateX(0)`), warna merah (`#dc2626`), aktif/dapat diklik.
   - State buka/aktif (`state-open`): toggle di posisi kanan (`translateX(22px)`), warna hijau (`#16a34a`), aktif/dapat diklik.

5. **Penyederhanaan Teks Status Pengambilan Data & Parity Log Riwayat**:
   - **Penyederhanaan Teks Status**: Mengeliminasi frasa `"Menunggu fetch jadwal"`. Untuk fase pengambilan data/jadwal (`NOT_FETCHED_YET`, `FETCH_RETRYING`, `STATUS_UNKNOWN`), status pill langsung menampilkan teks eksplisit `"Bot sedang dalam proses pengambilan data outlet"` (`is-pending`).
   - **Log Riwayat Aktivitas**: Format kartu riwayat aktivitas disamakan 1:1 dengan VB Outlet Drawer Admin: menampilkan role pill aktor (`Bot`, `Admin`, `Merchant`, `Info`), waktu WIB (`17 Sep 2026, 15:05 WIB`), judul aksi eksplisit, nama outlet, dan Store ID.

## Spesifikasi

1. **Brand Hero Card Action Grid & Clean Status Text (`brand_dashboard.html` & `styles.css`)**:
   - Kontainer `.brand-hero-actions` menggunakan `display: grid; grid-template-columns: repeat(2, 1fr); gap: 10px;`.
   - Elemen `.brand-status-pill` menggunakan `background: transparent !important; padding: 0;` untuk menampilkan teks status berwarna tanpa kotak latar belakang.

2. **Header Cleansing & Seamless Layout (`brand_dashboard.html` & `styles.css`)**:
   - Elemen `.theme-toggle` dihapus dari `.header-actions`, menyisakan hanya brand logo di kiri dan tautan customer service Bantuan WhatsApp di kanan.
   - Aturan CSS `.brand-dashboard-shell .app-header { border-bottom: none !important; }` menghilangkan garis separator bawah header.

## Handling

  ```bash
  docker compose build web
  docker compose up -d --no-deps web
  ```
  Perubahan hanya memengaruhi template HTML dan asset static backend Web (`web`/`fm-backend`). Container patroli bot (`fm-bot`) tetap beroperasi 24/7 tanpa interruption.
