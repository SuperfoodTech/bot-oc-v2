# Update v1.1.4

## Whats New

- Fallback dummy status Shopee sekarang hanya aktif pada dashboard local.
- Dashboard server tidak lagi mengubah status kosong atau `UNKNOWN` menjadi status buka.

## Spesifikasi

- Environment local ditentukan dari hostname `localhost`, `127.0.0.1`, atau `::1`.
- Status valid dari XHR/database tetap dipakai di semua environment.
- Status yang belum tersedia di server ditampilkan sebagai `Shopee: Status belum tersedia`.

## Handling

- `ON`/`OPEN` ditampilkan sebagai `Shopee: Buka`.
- `PAUSE`/`CLOSED` ditampilkan sebagai `Shopee: Tutup sementara`.
- `UNKNOWN` atau nilai kosong hanya menggunakan dummy `OPEN` di local; di server tetap `UNKNOWN`.
