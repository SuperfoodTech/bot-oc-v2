## 🚀 What's New in v0.0.1

### 1. Network Health Gate & Gated Retry
- **Fitur Baru**: Modul `src/core/network.py` yang menyediakan fungsi pengecekan koneksi internet cepat (`is_internet_available()`) menggunakan socket ping ringan ke Public DNS (`1.1.1.1` & `8.8.8.8` port 53).
- **Daemon Integration**: Pengecekan otomatis di [main-bot/src/daemon.py](file:///home/akbarhann/project/bot-oc/main-bot/src/daemon.py#L180-L200) sebelum setiap siklus patroli toko dijalankan.
- **Handling Terputus**: Jika internet kantor terputus, bot secara otomatis menunda pembukaan browser Selenium/panggilan API, mencatat peringatan log, dan masuk ke mode *pause* ringan (pengecekan ulang setiap 15 detik). Begitu internet pulih, patroli toko otomatis dilanjutkan.

### 2. PID-based Zombie Process Cleanup
- **Fitur Baru**: Fungsi `cleanup_driver_process(driver)` di [src/core/browser.py](file:///home/akbarhann/project/bot-oc/src/core/browser.py#L40-L70).
- **Proses Handling**: Menangkap PID spesifik dari proses ChromeDriver `driver.service.process.pid`.
- **Force Kill Fallback**: Jika `driver.quit()` mengalami penundaan/kebekuan (*hang/stuck*), sistem mengirimkan sinyal `SIGTERM` secara paksa ke PID spesifik tersebut agar RAM dan CPU Mini PC tetap bersih dari *zombie process*.

## 🛠️ Spesifikasi & Technical Handling

### A. Network Health Gate Specification
- **Metode Check**: Low-level C Socket `socket.create_connection((host, port), timeout=3.0)`.
- **Target Ping**: `1.1.1.1:53` (Cloudflare) & `8.8.8.8:53` (Google).
- **Resource Footprint**: Membutuhkan waktu CPU < 1 ms dan 0 Bytes RAM tambahan. Selama interval jeda 15 detik, proses Python berada pada mode OS *Idle/Sleeping State* (0.00% CPU usage).

### B. Zombie Process Cleanup Specification
- **Target Process**: `chromedriver` & `chrome` (Linux x86_64).
- **Isolation Scope**: Hanya menargetkan PID spesifik yang dibangkitkan oleh instansi Selenium tersebut (tidak mengganggu proses aplikasi lain di Mini PC).
- **SingletonLock Cleanup**: Otomatis menghapus file `SingletonLock` pada Chrome Profile (`src/data/chrome_profile_<username>`) sebelum browser dinyalakan untuk mencegah `SessionNotCreatedException`.

## 📐 Aturan Penamaan Versi (Semantic Versioning Rules)

Mulai versi 0.0.1 ini, setiap perubahan atau generasi kode baru **wajib** membuat dokumen rilis baru di dalam folder `update/<MAJOR>.<MINOR>.<PATCH>.md` dengan aturan berikut:

1. **MAJOR (Angka Pertama, contoh: `1.0.0`)**:
   - Digunakan saat ada perubahan arsitektur besar (*breaking changes*), perombakan ulang database, atau perubahan struktur dasar bot/API.
2. **MINOR (Angka Kedua, contoh: `0.1.0`)**:
   - Digunakan saat ada penambahan fitur baru (*new features*) yang signifikan tetapi tetap kompatibel (*backward compatible*).
3. **PATCH / FIX (Angka Ketiga, contoh: `0.0.1`)**:
   - Digunakan untuk perbaikan bug (*bug fixes*), penguatan *handling* error, refactoring kecil, atau optimasi stabilitas.
