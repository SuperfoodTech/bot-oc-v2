# Update v1.1.3

## Whats New

- Menampilkan label status Shopee terakhir di samping nama outlet pada dashboard mitra.
- Status `ON`/`OPEN` ditampilkan sebagai `Shopee: Buka`.
- Status `PAUSE`/`CLOSED` ditampilkan sebagai `Shopee: Tutup sementara`.
- Waktu buka pada pill selalu ditampilkan sebagai `HH:MM WIB`, tanpa tanggal, detik, atau fractional seconds.

## Spesifikasi

- Sumber utama label adalah field `shopee_status` dari response `/api/v1/user/login`.
- Worker mengisi field tersebut dari status XHR Shopee `/api/seller/store`: `OPEN` menjadi `ON`, sedangkan `CLOSED` menjadi `PAUSE`.
- Response kosong atau `UNKNOWN` hanya memakai fallback dummy `OPEN` untuk kebutuhan local/mock testing.

## Handling

- Nilai status XHR yang valid tidak ditimpa oleh fallback dummy.
- Nilai status yang belum dikenal dinormalisasi menjadi status buka untuk local testing dan diberi tooltip sumber status.
- Parsing timestamp tetap menggunakan timezone `Asia/Jakarta` (GMT+7).
