# Dokumentasi Rilis Update v0.2.8

Penyempurnaan UX mobile pada form Tambah Mitra dan penambahan custom dropdown.

**Tanggal Release**: 18 Agustus 2026  
**Jenis Update**: Patch UX

## Whats New

1. Dropdown Kepemilikan dan Paket Layanan menggunakan custom dropdown dengan tampilan visual yang konsisten dengan form.
2. Custom dropdown mendukung klik, keyboard Enter/Space, navigasi Arrow Up/Down, dan Escape.
3. Validasi form menggunakan pesan inline berbahasa Indonesia, termasuk validasi Store ID numerik dan format email.
4. Hint tanggal diperjelas bahwa format tampilan mengikuti perangkat pengguna.

## Spesifikasi

| Komponen | File | Perubahan |
|---|---|---|
| Custom dropdown | `src/backend/templates/admin_add_merchant.html` | Trigger, listbox, selected state, dan native value sync |
| Dropdown styling | `src/backend/static/css/styles.css` | Menu, hover, selected, focus, dan mobile behavior |
| Validasi | `src/backend/templates/admin_add_merchant.html` | Error inline lokal tanpa browser tooltip berbahasa Inggris |

## Handling

1. Nilai custom dropdown tetap disinkronkan ke elemen select yang dikirim ke endpoint backend.
2. Menu dropdown ditutup saat memilih option, menekan Escape, atau klik di luar menu.
3. Tidak ada submit data valid yang dilakukan selama validasi UI.
4. Deploy perubahan frontend/backend menggunakan:
   ```bash
   docker compose build web
   docker compose up -d --no-deps web
   ```
