# Dokumentasi Rilis Update v0.2.5

Penyederhanaan navigasi pada halaman khusus Tambah Mitra.

**Tanggal Release**: 18 Agustus 2026  
**Jenis Update**: Patch UX

## Whats New

1. Navigasi tab dashboard dihapus dari halaman `/admin/mitra/tambah` agar fokus utama tetap pada pengisian form.
2. Tombol `Tambah mitra` disembunyikan ketika pengguna sudah berada di halaman tambah mitra sehingga tidak ada CTA duplikat.
3. Navigasi kembali ke operasional outlet dipertahankan dalam bentuk arrow back dengan label yang jelas.

## Spesifikasi

| Komponen | File | Perubahan |
|---|---|---|
| Header | `src/backend/templates/admin_header.html` | CTA tambah mitra bersifat kondisional |
| Halaman form | `src/backend/templates/admin_add_merchant.html` | Tab navigation dihapus |
| Back navigation | `src/backend/templates/admin_add_merchant.html` | Link kembali ke operasional outlet tetap tersedia |

## Handling

1. Header brand tetap ditampilkan sebagai identitas aplikasi.
2. Pengguna tetap dapat kembali ke dashboard operasional melalui kontrol arrow back.
3. Perubahan tidak memengaruhi proses submit atau endpoint pembuatan mitra.
4. Deploy perubahan frontend/backend menggunakan:
   ```bash
   docker compose build web
   docker compose up -d --no-deps web
   ```
