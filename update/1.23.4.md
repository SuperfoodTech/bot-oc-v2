# Update Release 1.23.4

## Whats New
Penyederhanaan tampilan Virtual Brand Dedicated Dashboard (`/brand/{slug}`):
1. **Eliminasi Kartu Metrik Live/Abnormal**: Menghapus row metrik status live ("Live Buka", "Perlu Cek", "Live Tutup") dari Hero Card Brand agar antarmuka publik brand tampil lebih bersih, fokus, dan minimalis.
2. **Eliminasi Tombol & Daftar Outlet**: Menghapus tombol accordion "Daftar Outlet (N)" beserta tabel collapsible daftar outlet di bawah Hero Card Brand.
3. **Penyelarasan Tata Letak Hero Action**: Menyelaraskan tata letak tombol aksi brand menjadi full-width yang hanya berfokus pada tombol aksi "Lihat Jadwal" dan switch toggle status operasional brand.

## Spesifikasi
- **File Dimodifikasi**:
  - `src/backend/templates/brand_dashboard.html`: Menghapus markup `.brand-metrics-row`, `#outletsAccordionBtn`, `#brandOutletsList`, serta membersihkan fungsi rendering outlet yang tidak lagi digunakan di client-side JS. Cache buster stylesheet diperbarui ke `?v=20260917-brand-v2`.
  - `src/backend/static/css/styles.css`: Mengubah display layout `.brand-hero-actions` dari grid 2-kolom menjadi flex layout agar tombol "Lihat Jadwal" membentang rapi dan proporsional.

## Handling
- Pembersihan elemen DOM dilakukan secara aman tanpa menimbulkan error `null reference` pada script rendering dashboard brand.
- Riwayat aktivitas terbaru (`#brandHistoryLogs`), modal pause durasi, bottom sheet jadwal mingguan, dan proteksi schedule lock tetap beroperasi 100% normal.
- Zero-downtime deployment diaplikasikan pada container `fm-backend` (`web`) tanpa mengganggu container bot dan database.
