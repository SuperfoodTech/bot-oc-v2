# Update v1.1.8

## Whats New

- Pill `Bot` pada log mitra sekarang inline dan mengikuti panjang teks.
- Waktu action bot ditampilkan dengan pill kuning dan foreground putih.
- Informasi `Ditutup oleh bot sampai ...` ditampilkan dengan pill hijau dan foreground putih.
- Teks `Dibuka oleh bot` dihapus dari detail action open.

## Spesifikasi

- Action open hanya menampilkan label waktu action.
- Action close menampilkan label waktu action dan label target waktu buka.
- Log non-bot tetap menggunakan format sebelumnya.

## Handling

- Jika action close tidak memiliki target waktu eksplisit, pill hijau menampilkan `Ditutup oleh bot sesuai jadwal`.
- Tidak ada perubahan pada sumber data log; server tetap membaca log asli dan local Yolo tetap menggunakan dummy yang sudah dibatasi.
