# Update 1.17.0

## Whats New
- Penggantian filter redundan "Status Master" pada Tab Virtual Brand (VB) dengan filter operasional "Status Outlet" (`Status Outlet`).
- Opsi filter Status Outlet mencakup: `Semua status`, `Perlu cek` (`PERLU_CEK`), `Live Buka` (`OPEN`), `Live Tutup` (`CLOSED`), dan `Tutup Sementara` (`PAUSE`).
- Filter `Perlu cek` menyaring outlet yang membutuhkan perhatian admin (misal: patroli gagal, status error, atau kegagalan aksi toggle).

## Spesifikasi
- **Frontend HTML**:
  - `src/backend/templates/admin_tab_vb.html`: Memperbarui label dropdown `#vbMasterFilter` dan `#mobileVbMasterFilter` dari `Status Master` menjadi `Status Outlet` dengan opsi value `PERLU_CEK`, `OPEN`, `CLOSED`, dan `PAUSE`.
- **Frontend Logic (JavaScript)**:
  - `src/backend/templates/admin_dashboard.html`:
    - Fungsi `isVbOutletPerluCek(outlet)` diekstrak untuk mendeteksi kegagalan patroli dan error outlet secara terpusat.
    - Fungsi `matchesVbOutletStatus(outlet, statusFilter)` ditambahkan untuk memvalidasi status outlet sesuai pilihan filter.
    - `getActiveVbFilters()` dan `getFilteredVbBrandViews()` diperbarui agar memproses `filters.outletStatus` pada tingkat outlet (`outletScoped`). Jika filter outlet aktif, hanya brand yang memiliki outlet yang memenuhi kriteria yang akan ditampilkan.
    - `updateVbResultsSummary()` dan `getActiveVbAdvancedFilterCount()` disesuaikan dengan kriteria filter outlet.
- **Tests**:
  - `tests/test_schedule_ui_layout_contract.py`: Penambahan unit test `test_vb_outlet_status_filter_contract` untuk menguji keberadaan elemen HTML filter Status Outlet dan fungsi JavaScript pendukung.

## Handling
- Penyesuaian `outletScoped` memastikan penyaringan status outlet berjalan presisi tanpa merusak visualisasi grup brand Virtual Brand.
- Paritas filter antara versi desktop (`#vbMasterFilter`) dan mobile (`#mobileVbMasterFilter`) tetap terjaga penuh melalui `syncVbMobileFilterSelectsFromDesktop()`.
- Zero-downtime deployment wajib menggunakan `docker compose build web` dan `docker compose up -d --no-deps web` agar container `fm-backend` diperbarui tanpa menginterupsi container `fm-bot` atau `fm-postgres`.
- Seluruh 77 unit test pada test suite terverifikasi lulus (100% pass).
