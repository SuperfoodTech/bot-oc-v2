# Dokumentasi Rilis Update v0.3.3

Perbaikan bug crash daemon bot akibat inkompatibilitas skema dataclass MerchantOutlet.

**Tanggal Release**: 20 Agustus 2026  
**Jenis Update**: PATCH/FIX Bug Stabilitas

## Whats New

1. Penanganan error `MerchantOutlet.__init__() got an unexpected keyword argument 'hp'` yang menyebabkan bot daemon crash pada saat inisialisasi awal.
2. Penambahan kembali field `hp: str = ""` pada dataclass `MerchantOutlet` agar kompatibel dengan pemanggilan dari database internal (`db.py` dan `worker.py`).
3. Penyediaan nilai default untuk semua field utama `MerchantOutlet` agar tidak memicu error missing required positional arguments sewaktu instansiasi dengan data parsial dari query database.

## Spesifikasi

| Komponen | File | Perubahan |
|---|---|---|
| Dataclass Skema | `src/core/sheets.py` | Restorasi field `hp` dan penambahan nilai default pada semua field |

## Handling

1. Jalankan git pull untuk memuat pembaruan.
2. Jalankan perintah restart untuk memuat ulang kode di container:
   ```bash
   docker-compose -p fm restart web bot
   ```
